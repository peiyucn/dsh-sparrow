Desk One 同桌

One desk for you and harness.

Sticky notes, a task board, a read-only calendar and AI-written notebook review in one sidebar panel — plus a header button that turns a plain sentence into a prefilled prompt for DSH.

dsh plugin --profile web add @dsh-sparrow/dsh-desk-one

Docs · npm

Index URL

https://dsh.pyai.site/market/index.json

Use it in DSH

  1. Enable the experimental feature: Plugins → Experimental plugins → More → Custom plugin markets
  2. Open Plugins → Discover → Add index source
  3. Paste the index URL above

The market marks which versions work with the DSH you are running. Every plugin here supports only the exact DSH version line stated in its version number.

More plugins

Three small tools come with the desk and are installed separately: chat suggestions (dsh-chat-fim), CodeBuddy credits (dsh-codebuddy-credits) and tone skins (dsh-theme-tone).

文档 · npm

索引地址

https://dsh.pyai.site/market/index.json

在 DSH 里使用

  1. 先打开实验性功能：插件 → 实验性插件 → 更多 → 自定义插件市场
  2. 进入 插件 → 发现 → 添加索引源
  3. 粘贴上面的索引地址

市场会按你当前运行的 DSH 版本标出可用版本。每个插件只支持其版本号所标示的那一条 DSH 版本线。

更多插件
