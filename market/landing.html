DeepSeek Harness 插件合集：同桌（Desk One），以及三件小工具。

Desk One 同桌

One desk for you and harness.

Annotations, a sticky wall, a three-lane task board, a read-only calendar mirror and session management all live in one sidebar panel.

The same objects the panel writes are exposed to harness through a bundled skill and 19 agent tools, so you can ask in the conversation and work alongside harness.

Package @dsh-sparrow/dsh-desk-one

Index URL

Paste this into Plugins → Discover → Add index source.

https://dsh.pyai.site/market/index.json

Install

  1. Open Plugins → Add plugin, enter @dsh-sparrow/dsh-desk-one, then follow the install and enable flow.
  2. Or use this market: turn on Custom plugin indexes under Plugins → Experimental plugins, open Plugins → Discover → Add index source, and paste the URL above. Desk One is the first card.

The market marks which versions fit the DSH you are running. Every plugin here supports only the exact DSH version line named in its version number.

More plugins

Three small tools install separately, the same way.

和 harness 共用的一张办公桌。

笔记批注、便签墙、三泳道任务板、只读日程镜像和会话管理，都收在一个侧栏面板里。

面板写入的同一套对象，也通过随包 skill 和 19 个 agent 工具交给 harness：你可以在对话里直接说，和 harness 一起办公。

安装

  1. 打开 插件 → 添加插件，输入 @dsh-sparrow/dsh-desk-one，按安装 / 启用流程操作。
