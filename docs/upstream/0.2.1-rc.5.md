## 0) 一句话结论

* **没有必须改的插件代码**：rc.5 的实质改动集中在聊天 UI 的「推理（reasoning）签名块」显示处理上，
  五个插件依赖的公开槽位、服务、导出与样式锚点均未变。
* **但版本门必须跟**：五个活跃插件的 peer 仍精确钉 `0.2.1-rc.4`，rc.5 宿主会把它们判为不兼容
  **静默跳过**（机制沿用 rc.4 文档记录：`profile.ts:760-766` / `plugin-compatibility.ts:62-71`；
  rc.5 无 tag，未按 rc.5 源码复核）。用户升到 rc.5 后表现为「插件全没了」，不报错。故本轮需发新版。
* 版本线从 `0.2.1-rc.4` 对齐到 **`0.2.1-rc.5`**。
