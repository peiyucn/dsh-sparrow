## 2. 官方变化

- base composition 不再固定 `searchProvider: deepseek-search-api`；`dsh-web` 按当前模型路由选择搜索 provider：DeepSeek 模型路由走 legacy Messages search，其它路由仍走 DeepSeek Search API。
- 设置页新增 **Automatic** 搜索 provider 选项；套用固定 provider 的 composition / profile 不受影响。
- `web-search-deepseek` 支持结果项自带 `snippet`，不再必须从 citation 文本块拼接。
- 其余为 web 设置页、tool-web、版本号与测试调整。
