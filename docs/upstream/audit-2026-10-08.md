## 4. 注释精简（owner 交办）

### 4.1 规则

代码里只留「**删掉它，后人会改错**」的信息：非显然的取值理由、反直觉的坑与「别改回去」、对外契约坐标（官方 attr / token / 选择器 / 槽位 id）。
删除：事故叙事（日期、owner 原话、报障经过）、版本沿革与被推翻的结论、Markdown 表格与清单式推演、官方源码 `文件:行号` 引用、`@param`/`@returns`、复述代码的注释、以及**写进 CSS 模板字符串里会随产物出货的注释块**（压成一行 banner）。
详细论证归 `plugins/<插件>/docs/spec/`，代码里只留指针级的信息。

### 4.2 结果

| 插件（`src/`，`*.ts`/`*.tsx`） | 注释行 before | after | 占比 before → after |
| :--- | ---: | ---: | :--- |
| dsh-chat-fim | 644 | 441 | 21.3% → 15.6% |
| dsh-archive-manage | 870 | 724 | 19.8% → 17.0% |
| dsh-file-manage | 412 | 282 | 24.8% → 18.4% |
| dsh-codebuddy-credits | 1758 | 730 | 26.7% → 13.2% |
| **dsh-theme-tone** | **6074** | **1170** | **68.9% → 30.4%** |
| **合计** | **9758** | **3347** | **39.9% → 18.6%** |

* `dsh-theme-tone` 剩余占比偏高是**契约密度**所致（`glass.ts` / `surface.ts` / `constants.ts` / `anchors.ts` / `popover.ts`
  逐个常量都在解释「为什么是这个值 / 别改回去」），不是残留的叙事稿：**最长连续注释块 ≤6 行**（全 `src` 已无 ≥7 行的块），
  不再有原来的 60 行论证稿。
* 测试文件（`test/`）同步精简（theme-tone 单插件 1981 → 1119 行注释）；**断言、字符串字面量、`test()` 名称一律未动**。
* 四个守卫脚本同步精简（`plugin-set` / `check-no-local-paths` / `check-dsh-pin` / `check-plugin-docs`，合计 301 → 107 行注释）。

### 4.3 怎么证明「只动了注释」

不能只信「diff 看着像注释」。本轮用三层机械校验（工具在 `TEMP/`，不入仓库）：

1. **AST 骨架 + 字面量逐序比对**：用 TypeScript printer 以 `removeComments` 归一化 HEAD 与工作树两侧源码 ⇒ 骨架（非字符串部分）必须**逐字节相同**；再按序比每个字符串 / 模板字面量，要求「去掉 CSS 注释并折叠空白后」相同。
   ⇒ 结论：**113 个文件里 112 个纯注释改动**；唯一的骨架差异是 `nav-pin.ts`（§3 第 1 条刻意删掉的死函数 `escapeCssString`）——
   即代码、选择器、声明、数值、字符串**没有任何非预期改动**。
   *（模板字符串里的 CSS 注释**不是** TS 注释，printer 不会删——所以这一步能把「CSS 声明是否被误删」也一并盖住。）*
   *局限（如实记）：printer 会按「导入是否被使用」做**导入省略**，所以「删掉一个本来就没被使用的 import」（§3 第 2、3、4 条）在这一层看不出来；
   但这三条的属性是**改了也不可能影响行为**（未使用的导入在产物里本就不存在），不构成盲区。*
2. **`tsc --noEmit --noUnusedLocals`**：五个插件全部 exit 0 且告警 0。
3. **测试**：根 `pnpm run verify` exit 0（见 §7）。

> 过程诚实记录：多个执行者中途出现过「`edit` 吃掉行尾换行 ⇒ 注释与下一行代码并成一行」与「误删一行代码」两类错误，
> 均被上述第 1 层校验（或各自的自查脚本）抓出并修回。**这正是不能只看 `node --check` 的原因**——代码被并进注释后语法仍然合法。

### 4.4 副产物：包体减半

`tsc` 默认 `removeComments: false`，所以注释**随 `lib/` 出货**。theme-tone 的 `npm pack` 结果：
