## 3. 版本门 / 仓库改动（已落地）

1. 4 个存续插件 `package.json`：`version` → `0.2.2-rc.3`；`peerDependencies` + `devDependencies` 的 `@deepseek-ai/dsh*` 精确版本 → `0.2.2-rc.3`（`cordis` 仍 `^4.1.0`）。`dsh-archive-manage`：仅 peer/devDeps 跟版，`version` 仍 `0.2.2-rc.1.1`（退役不发布）。
2. 根 `package.json` version → `0.2.2-rc.3`。
3. `pnpm-workspace.yaml`：`minimumReleaseAgeExclude` / `overrides` 各 83 条 dsh + 7 条 vendor；补 `dsh-error` / `dsh-client-ui-sidebar-right` / `dsh-client-ui-sidebar-documentpreview`（rc.3 发布不足 24h，供应链策略必须逐条放行）。
4. README 环境要求行（根 2 份 + 5 个插件 × 中英）：`0.2.2-rc.1` → `0.2.2-rc.3`。
5. `scripts/check-dsh-pin.mjs`：提示语中的插件/文件数改为「当前 5 个插件 = 12 份文件」。
6. 结构守卫：desk-one 的版本断言从 `peerDependencies` 机械派生，**无需改硬编码**；其余插件无 rc.1 硬编码。
7. CHANGELOG：4 个存续插件新增 `[0.2.2-rc.3] - 2026-11-14` 段（chat-fim / codebuddy 的 `0.2.2-rc.1.1` 预写草稿合并进 rc.3 —— 该版本从未发布；desk-one 的 `Unreleased` 段转为 rc.3 首发段）。
8. market 索引为派生数据，**不手改**：本轮不发布前不重生成；发版后由 `market.yml` 从 npm 重生成。
