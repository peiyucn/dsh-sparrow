## 0) 一句话结论

* **必须改代码**：`dsh-codebuddy-credits` 的积分投影注册（`register()` 变异步）与冷会话读取
  （`sessionController.inspect()` 被删除）；`dsh-theme-tone` 的一个官方 token 被删除。
* **必须跟版本门**：四个活跃插件的 peer 仍精确钉 `0.2.1-rc.5`，0.2.2 宿主会把它们判为不兼容并跳过
  （`plugin-compatibility.ts`；用户表现为「插件全没了」且不报错）。版本线从 `0.2.1-rc.5` 对齐到
  **`0.2.2-rc.1`**。
* `dsh-archive-manage` / `dsh-chat-fim` **无编译级代码改动**（行为面见 §3）。
* **Node 门槛**：官方要求 Node.js >= **24.9**（`engines.node = ">=24.9.0"`）；本机与 CI 的 Node 24.x 满足。

## 2) 真实差量（与插件作者相关）

**依赖与工具链**

* `engines.node`：`^22.19.0 || >=24.0.0` → **`>=24.9.0`**。
* vendor：`cordis 4.0.5 → 4.1.0`、`cordis-plugin-loader 1.0.6 → 1.1.0`、`-include 1.0.10 → 1.1.0`、
  `-group 1.0.5 → 1.1.0`、`-timer 1.1.7 → 1.2.0`、`cosmokit 1.8.6 → 1.9.0`、`schemastery 3.18.5 → 3.19.0`。
* pnpm `11.28.5`、TypeScript `^6.0.3` 不变。

**破坏性变更（命中本仓库的）**

1. **Session Projection 契约重做**（`packages/session/session-projection`）：
   - `register(definition)` → **`Promise<ProjectionHandle<S>>`**；返回的运行期值同时是 effect disposer
     （官方兼容面）。旧「当同步 disposer 用」的写法仍能跑但已弃用。
   - `SessionProjectionStateMap` **删除**；`ProjectionDefinition<K extends string, S>` 不再经该表约束。
   - 注册表级 `stateOf(session, key)` / `cachedSnapshot()` 标 `@deprecated`；live 读改用
     `handle.stateOf(session)`。`sessionProjectionCache.cachedSnapshot(header, keys)` 不变。
   - Projection 实时帧改为每帧携带 `changes[]`；`snapshot()` 只计算被选中的单元。
2. **`sessionController.inspect()` 被删除**（该包重组为 history/state/web）。冷会话读持久化事件改用
   官方公开面 `ctx.sessionPersistence.open(id, 'read')` + `SessionHandle.read()`（读完整日志）+ `close()`。
3. **模型角标**：`@deepseek-ai/dsh-client-ui-deepseek-model-label-1017` 包删除；`LlmModelInfo.badge`
   （`{ text: LocalizedText, tone }`）改由目录下发。`conversation.input.model.label` 的官方 fallback
   渲染「名称 + 角标」（触发器在名称前、菜单在选项后），扩展接管后必须自行渲染角标并使用
   `ctx.locale.resolveText` 解析多语言。
4. **Cordis 4.1 / Loader 1.1 / Include 1.1**：配置访问统一（`fiber.effectiveConfig`、`ctx.fiber` 嵌套）、
   EntryTree 的 `write()` 移除、Include journal 持久化。本仓库只使用 cordis 公共面与 patch 文件，
   未直接继承 EntryTree（patch 语法未变）。
5. 其它（本仓库未命中）：右键菜单改名 `ContextMenuTarget`、工具执行器拆分
   （`tools.resolve/executable`、`when` 条件工具）、`ui-conversation` 的 `InputState.phase` 新增
   `'sending'`、`ui-commands` 内置命令搬家、`host-webserver.renderIndex(html, peer)`、
   `llm` 的 `purpose` 类型化、`storage-domain` 兼容读语义。
