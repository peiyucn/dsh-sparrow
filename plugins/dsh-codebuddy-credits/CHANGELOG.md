## 0.1.0-alpha.1

- Initial release: CodeBuddy credits as a DSH LLM provider
- Official API key authentication only (`CODEBUDDY_API_KEY` or DSH credential vault)
- Built-in model catalog plus CodeBuddy catalog discovery (Settings → Models → Get available models)
- Streaming-only chat completions with official request identity headers
- Reasoning effort per model (off/minimal/low/medium/high/xhigh/max)
