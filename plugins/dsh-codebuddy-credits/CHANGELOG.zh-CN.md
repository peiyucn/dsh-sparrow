# 更新日志

所有用户可感知的改动都记录在此。
See [English](./CHANGELOG.md).

## 0.2.0-rc.2（2026-09-30）

- 版本线对齐官方 dsh 0.2.0-rc.2。
- 输入框下方的会话积分标签现在与同一行的其它标签样式一致。
- 加载时改为显示加载图标，不再显示「加载中…」文字。
- 修复升级到 dsh 0.1.7 后插件不工作的问题。
- 修复重启后积分清零的问题。
- 修复新建会话页上的 CodeBuddy 入口与右上角按钮重叠的问题。
- 修复模型选择器分组标题的背景与悬停颜色错误。
- 布局变窄时，CodeBuddy 入口收成只有图标的 logo。
- 修复额度面板短暂出现在错误位置的问题。
- 新建会话页的入口现在也会收成只有图标的 logo。

## 0.1.5-rc.2.2（2026-09-21）

- 重启后积分不再清零，重新打开旧会话仍显示完整累计。
- 积分弹层宽度缩小。
- 点击积分弹层里的用户名可打开 CodeBuddy 个人主页。

## 0.1.5-rc.2.1（2026-09-11）

- 会话积分现在显示在输入框下方的统计行里，点开可看按模型分组的明细。
- 点**「获取可用模型」**后，设置卡、额度卡与模型选择器一起更新。
- 保存 Key 后首次即可正确加载你账号的模型清单。
- 积分系数刚好不到一百万时不再显示 `1000K`，而是 `1M`。
- 请求不再永久悬挂，超时后会结束。
- 更换或清空 Key 后，不会再回退显示旧账号或旧模型清单。

## 0.1.5-rc.2（2026-09-10）

- 版本线对齐官方 dsh 0.1.5-rc.2。
- 修复会话积分有时漏计回复最后一部分的问题。
- 设置卡现在会列出你的 Key 可用的模型，并提供**「获取可用模型」**按钮。
- 模型名不再带积分系数后缀，系数与上下文长度分开显示。

## 0.1.2-rc.1.2（2026-09-09）

- dsh 升级到本插件尚不支持的版本时，插件会自动停用。
- 修复图片无法送达支持视觉的模型的问题。

## 0.1.2-rc.1.1（2026-09-07）

- **Max 模式**：额度卡里的开关可把所有推理模型锁定在 Max 档位。
- 该锁定不影响其它 provider 的模型。

## 0.1.2-rc.1（2026-09-05）

- 首发：把公司发的 CodeBuddy 额度接成 DSH 的 LLM provider。
- 在**设置 → 模型**的 **CodeBuddy Credits** 行配置；清空 Key 即停用 provider。
- 模型选择器显示每个模型的积分系数与可用推理档位。
- 模型清单完全跟随已保存的 Key；未配置 Key 时不发起任何网络请求。
- 会话页头部的额度入口可展开面板，显示账号与当期额度。
- 输入框下方统计行显示本会话积分，每轮另有积分标签。
- 凭据名改为 `CODEBUDDY_CREDITS_API_KEY`；旧名仍可用并自动迁移。
- 现在可以向支持图片的模型发送图片。
