# 更新日志

简体中文 | [English](CHANGELOG.md)

## 0.1.5-rc.2（2026-09-18）

- 首次发布，发布到 `latest` 通道。
- 设置 → 常规新增**色调**行，就在官方**外观**行正下方；浅色轴与深色轴各选各的色调，各自独立记忆。
- 每轴四款色调 + 一款**默认**：深色 = 深空（蓝紫）、余烬（红）、幽林（绿）；浅色 = 霜蓝、樱花（粉）、苔青（绿）。**默认**不覆盖任何 token、不画任何图层，所以「未被改动过的官方外观」永远只差一次点击。
- 每款色调会重画应用底色、左栏填充，以及铺在整屏上的柔光（上方光源、下方纵深、左栏光晕），外加细腻的颗粒质感。
- 深色轴沿用 pyai.site 的深空调色板（近黑地面 + 一束暖金光）；浅色轴与它严格镜像：官方白地面 + 由该色调自己打出的光。
- **抬升面** —— 菜单、对话框、抬升卡片 —— 继承该色调的色相；交互态、分隔线与滚动条也跟着染色。
- **浅灰内嵌面** —— 代码块与输入框上方的三张停靠卡（待办 / 目标 / 对话排队）—— 按该色调染色，比页面背景重一档，边界一眼可辨。
- 运行中那一行扫过的**扫光带**照本插件自己的背景重画，不再在染过的地面上显出一条本色方块。
- **悬停预览卡**（官方把它的底色与字色写死在组件里）重新上色，跟着主题走，不再是固定的深灰块。
- 首页**还没选工作区**时，输入框卡片让回官方那圈虚线框：本插件撤掉自己的悬浮投影与内边距光，
  让虚线成为唯一边界（两套边缘叠着看不和谐）。
- 输入框左下那两个圆按钮（`+` 命令面板 / 附件）默认不再带实色底，露出卡片自己的玻璃；悬停底照旧保留。
- 顶栏与输入框的玻璃效果：输入框变成浮在背景之上的半透明模糊卡片，并加了缝挡板，滚过的正文不再从停靠卡之间的缝里透出来。
- **右边栏**自己补画一遍背景的光与颗粒（它被抬到内容层之上后吃不到背景层）。
- 会话区拖动滚动条时，**拖拽条**不再压住顶栏。
- 色调卡**预览**各自的效果（底色 + 上下染色 + 左侧光晕），不再是一块纯色。
- 宿主缺少依赖能力时，插件**不启动**；浏览器缺少背景层所需的 CSS 特性时**自停用**并记一条面向用户的告警。
