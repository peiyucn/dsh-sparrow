# 更新日志

简体中文 | [English](CHANGELOG.md)

## 0.2.0-rc.2（2026-09-30）

- 版本线对齐官方 dsh 0.2.0-rc.2。
- 修复 dsh 0.2.0-rc.2 下分组菜单的分组标题（模型选择器、命令弹窗）失去主题质感的问题。
- 新增：选了任一色调后，**轮次导航在窄对话列不再消失**（官方 900px 断点提到 700px；更窄时悬停右侧轨道浮现），并收紧会话内容每侧留白（官方 88px → 120px），右侧拖拽条不再挤占导航。这是原 `dsh-nav-pin` 插件的功能，已并入本插件（**官方默认色调下不生效**）。
- 顺手修掉官方拖拽条的一个小毛病：悬停「调整对话宽度」的拖拽条时，光带不再偏在下方，而是跟随指针（**不选色调也生效**）。
- 修复收起右侧栏后，会话区右侧常驻一片发白色块（打开过一次右侧栏就会出现）。
- 修复右侧栏的文件预览无法滚动（长文件滚不动）。
- 修复问答卡、计划审阅卡、归档页、云端文件页**没有纹理与打光**；归档页 / 云端文件页弹出后背景也不虚化。
- 恢复弹窗遮罩的背景模糊（官方 0.1.7-rc.2 有意去掉，按你的要求加回）。
- 修复展开的「思考」行吸顶时的黑框，以及模型选择器等**分组标题**的背景条与串色。
- 修复顶栏的金光被挡住、各类浮层打光强弱不一致。
- 修复输入框与顶栏玻璃在深浅两档的表现；拖拽条与顶栏不再穿模。

## 0.1.5-rc.2（2026-09-21）

- 首次发布。
- 设置 → 常规新增**色调**行，就在官方**外观**行正下方：浅色与深色各选各的，各自独立记忆。
- 带来几款**色调皮肤**：深色 = 深空、余烬、幽林；浅色 = 霜蓝、樱花、苔青。
