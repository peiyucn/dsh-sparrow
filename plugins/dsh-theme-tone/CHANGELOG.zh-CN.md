# 更新日志

## 0.1.5-rc.2（2026-09-18）

- 首次发布，发布到 `next` 通道供验证。
- 设置 → 常规新增**色调**行，就在官方**外观**行正下方；浅色轴与深色轴各选各的色调，各自独立记忆。
- 每轴四款色调 + 一款**默认**：深色 = 深空（蓝紫）、余烬（红）、幽林（绿）；浅色 = 霜蓝、樱花（粉）、苔青（绿）。**默认**不覆盖任何 token、不画任何图层，所以「未被改动过的官方外观」永远只差一次点击。
- 每款色调会重画应用底色、左栏填充，以及铺在整屏上的柔光（上方光源、下方纵深、左栏光晕），外加细腻的颗粒质感。
- 深色轴沿用 pyai.site 的深空调色板（近黑地面 + 一束暖金光）；浅色轴与它严格镜像：官方白地面 + 由该色调自己打出的光。
- **抬升面** —— 菜单、对话框、浮动提示条、抬升卡片 —— 继承该色调的色相；交互态、分隔线与滚动条也跟着染色。
- 顶栏与输入框的玻璃效果：输入框变成浮在背景之上的半透明模糊卡片，并加了缝挡板，滚过的正文不再从停靠卡之间的缝里透出来。
- 色调卡**预览**各自的效果（底色 + 上下染色 + 左侧光晕），不再是一块纯色。
- 宿主或浏览器缺少所需能力时，插件**自停用**并记一条面向用户的告警，而不是在不认识的契约上运行。
