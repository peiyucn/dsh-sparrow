# 更新日志

简体中文 | [English](CHANGELOG.md)

## [0.2.1-rc.4] - 2026-10-28

- 适配官方 dsh 0.2.1-rc.4（Web 与桌面端）。
- 对话区顶栏、输入框、右栏顶栏均为半透明磨砂玻璃；顶栏原有边框保持不动。
- 输入框玻璃更亮，边缘光改为对称（每条边中段最亮、两端淡出）；悬浮阴影收小，不再在窗口底部压出一条暗带。
- 两个顶栏带上与左栏同一片暖色页面光；填充压深一档，光读起来是「反光」而不是边框。
- 输入框底下的实色条已移除，改为透出页面地面光；滚动时正文不再从输入框下沿、统计胶囊行、停靠卡之间，以及右栏打开时的窗口底部漏出。
- todo / goal / 待发消息列表三张停靠卡改为不透明抬升面：多张叠放时观感一致，不再只有最上面一张像磨砂。
- 模型选择列表的分组标题改为不透明底，滚动时条目不再从标题文字下穿过。
- 右栏里 markdown / 纯文本预览与文件树：滚动条从顶栏下沿开始，正文从顶栏玻璃下滚过。
- @ / 斜杠 候选菜单：还有更多结果时改为淡出列表自身的条目（不再出现多出来的一条高亮带），滚到底部时淡出消失。

## [0.2.1-rc.3] - 2026-10-24

- 适配官方 dsh 0.2.1-rc.3（Web 与桌面端）。

## [0.2.1-rc.2.1] - 2026-10-22

- 色调不再在背景上叠噪点（颗粒）纹理。这是肉眼可见的变化：表面更干净，深色下的大面积留白尤其明显。
- 滚动明显更顺畅，多个会话同时运行时最明显。
- 会话之间来回切换也更顺畅。

## [0.2.1-rc.2] - 2026-10-18

- 适配官方 dsh 0.2.1-rc.2（Web 与桌面端）。
- 「设置无法保存」的提示在新版 dsh 上恢复准确（旧的「非本机回环地址」说法已不适用）。
- 滚动与「生成中（思考）」时更流畅：流式输出期间不再每次更新都触发插件的整轮重测，而是等输出停下再补测——长会话内容越多也不会越拖越慢。
- 「模型已更新」通知卡不再被主题各层遮挡或染色，外观与其它浮层一致。

## [0.2.0-rc.2] - 2026-10-08

- 适配官方 dsh 0.2.0-rc.2（Web 与桌面端）。
- 菜单与弹出层由实色面改为半透明 + 模糊，与 dsh 其它部分一致。
- dsh-nav-pin 已并入本插件：选了色调后，窄窗口下轮次导航不再消失，内容两侧留白也更宽；无需再单独安装 dsh-nav-pin。
- 模型回复（含思考）期间的滚动更流畅了。

## [0.1.5-rc.2] - 2026-09-22

- 首次发布。
- 设置 → 常规的「外观」下方新增「色调」行：浅色与深色各选各的，分别记忆。
- 多款色调皮肤：深色 = 深空、余烬、幽林；浅色 = 霜蓝、樱花、苔青。
