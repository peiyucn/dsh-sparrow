## 0.1.2-rc.1（2026-09-05）

- 版本对齐官方 dsh 0.1.2-rc.1（稳定线）。
- 翻页与删除的并发修复：快速关开面板或点击重试后，陈旧页不再混入新列表、「加载更多」不再卡死，迟到的删除回调不再误关新弹出的确认框。
- 请求在面板关闭后自行停止（15s 上限）不再无限挂起，计数在面板断开时立即停止翻页，关闭的面板不再持续消耗 API 配额。
- 侧边栏「云端文件」按钮与 Settings 同宽对齐（与归档入口一致）。
- 「加载更多」移到文件列表末尾，每页加载后自动滚到列表底部（按钮不再固定在面板底部）。
- 面板底部新增 🐦 dsh-sparrow 品牌行。
