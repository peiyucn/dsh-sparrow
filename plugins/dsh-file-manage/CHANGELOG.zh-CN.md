# 更新日志

简体中文 | [English](CHANGELOG.md)

## 0.2.0-rc.2（2026-09-30）

- 版本线对齐官方 dsh 0.2.0-rc.2。
- 加载指示器改为 dsh 0.2.0 所用的样式。
- 加载时只显示指示器，不再显示「加载中…」文字。
- 打开面板时不再先闪一下上一次的列表。
- 修复云端文件列表加载失败的问题。
- 修复升级 dsh 后文件操作失败的问题。
- 「云端文件」入口移到侧边栏顶部，与「插件」「自动化任务」并列；点开后是中央区页面，不再是弹窗。
- 云端文件页不再压暗界面其余部分；回到对话用侧边栏或 New Session。
- 修复云端文件页文字比别处偏大的问题。
- 「dsh-sparrow」品牌行移到页面左下角，并去掉它上方的分割线。

## 0.1.5-rc.2.1（2026-09-11）

- 「加载更多」每次加载 20 条，不再是 100 条。

## 0.1.5-rc.2（2026-09-10）

- 版本线对齐官方 dsh 0.1.5-rc.2。
- 加载指示器改为与 dsh 界面其余部分一致。
- Esc 现在先关删除确认框，不再在面板关闭后留在屏上。

## 0.1.2-rc.1.1（2026-09-09）

- 遇到本插件尚不支持的 dsh 版本时，插件自动停用，dsh 仍可正常使用。

## 0.1.2-rc.1（2026-09-05）

- 版本线对齐官方 dsh 0.1.2-rc.1（稳定线）。
- 修复快速关开面板或点重试后文件列表出错的问题。
- 面板关闭后请求即停止，取消掉的文件计数不再继续消耗你的 API 额度。
- 侧边栏「云端文件」按钮宽度与 Settings 对齐。
- 「加载更多」移到文件列表末尾，每页加载后列表滚到底部。
- 面板底部新增 🐦 dsh-sparrow 品牌行。

## 0.1.0 (2026-09-02)

- 首个稳定版。

## 0.1.0-alpha.3 (2026-09-02 · pre-release)

- 与上一版相比无用户可感知的变化。

## 0.1.0-alpha.2 (2026-09-01 · pre-release)

## 0.1.0-alpha.1 (2026-09-01 · pre-release)

- 首个版本。
- 侧边栏「云端文件」入口：每页列出 20 个云端文件，可加载更多、删除文件、复制文件 ID。
- 显示 25 GiB 空间已用多少，以及当前已加载多少个文件。
- 复用 dsh 里已配置的 DeepSeek 连接；不在本地保存任何数据。
