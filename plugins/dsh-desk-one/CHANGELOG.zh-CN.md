# 更新日志

[English](CHANGELOG.md) | 简体中文

`dsh-desk-one` 的所有用户可感知变化都记在这里。格式遵循 Keep a Changelog，版本号跟随官方 DSH 发布线。

## [0.2.2-rc.5] - 2026-11-19

- 任务卡描述默认收起为一行，点击展开；整卡可收起为 compact 行，保留标题、颜色、截止日期和已挂会话数量；两种状态跨刷新保留。
- 任一会话运行中时，整卡按任务卡自己的五色 accent 显示运行环；归档条目同样提示；减少动态效果时改为静态环。
- 新会话任务捕获增加一段常驻 system prompt：首条消息像跟踪事项时先问一次，先查本会话是否已有关联任务，已有未挂任务时先问补挂，不静默建卡或改关联。
- `desk_task_list` 支持按当前会话过滤；`desk_task_update` 支持把本会话补挂到已有任务，或按 id（`unlink_session_ids`）/ 本会话（`unlink_current_session`）解绑会话。
- 一并发布此前未发版改动：归档区刷新与两步确认、会话彻底删除二次确认、会话列表分页/排序/时间显示、便签与任务统一五色板。
- 适配官方 dsh 0.2.2-rc.5（Web 与桌面端）；官方 web search 默认变化不影响本插件。
- 批注输入框只能显式「取消」关闭：点输入框外或按 Esc 都不再关闭，空内容也不关；有内容时第一次点「取消」进入二次确认，空内容一次即关；打开期间不能直接替换成另一处批注，先取消。
- Microsoft Outlook 浏览器登录现在用宿主 web server 的实际端口生成 OAuth 回调；桌面端 window.location 没有端口时此前会回调到 80、永远回不来。成功页也不再自动跳回 `/`。
