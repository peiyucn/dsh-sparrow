# 更新记录

[English](CHANGELOG.md) | 简体中文

`dsh-desk-one` 的用户可感知改动都记在这里。格式遵循 Keep a Changelog，版本号与官方 DSH 发布线保持一致。

## [Unreleased]

* **日期格式**：会话列表、归档 / 回收站、笔记批注记录等日期时间改为跟随界面语言——中文界面显示「11月13日」「2026/11/13」，不再出现英文月份或英文日期顺序。

* **审阅会话复用**：再次点开同一篇笔记时回到这篇笔记已有且仍可用的审阅会话（按宿主持久化的笔记身份匹配；已删除 / 归档 / 换工作区的会话不复用），不再每次新建；没有可用会话时才新建。

* **审阅输入框引导**：位置与字体和官方 placeholder 完全一致（与光标同一起点、同一行高与字号），停靠态单行省略、空白会话两行截断。

* **会话列表**：每行新增「复制会话名称」「复制会话 ID」两个按钮（活跃 / 归档 / 游离 / 回收站都可用），复制成功 / 失败直接在按钮上反馈。
* **审阅高亮**：一轮审阅后，代码视图把本轮新增 / 改写的行就地高亮，颜色与底部「本轮改动」同源，+A −D 计数与高亮行保持一致。

* **审阅引导**：只要是审阅会话（空白新会话与对话已开始的都算），输入框为空时始终显示审阅操作引导，不再退回官方 placeholder；开始输入后消失，清空后重新出现。

* **审阅底栏**：「本轮改动」无改动时不再显示「持平」标签，只在有改动时显示 +A −D。

* **审阅底栏**：第二段不再套一层菜单，直接换成清单笔 / 时钟图标打开批注草稿 / 批注记录浮层（再点一次关闭）；图标颜色跟随按钮文字。
* **MD / 代码**：改为官方「当前查看器」按钮 + 下拉菜单（只有 Markdown / 代码两项，默认代码）。

* **官方预览审阅入口**：按钮位置固定在官方头部按钮之后；当前会话已是审阅会话时，点它原地切回审阅 tab，不再新开会话。
* **MD / 代码**：改成两个官方 ghost 图标按钮（MD / 代码），默认代码。
* **审阅引导**：从输入框下方的气泡改成输入框内 placeholder 式提示，输入或开始对话后消失。

* **审阅底栏浮层**：批注草稿 / 批注记录 / 本轮改动浮层支持点击其它位置或按 Esc 关闭；箭头菜单沿用官方 Menu 的外点关闭。

* **MD / 代码切换**：改为官方 `SegmentedTabs` 默认样式（两档，默认代码）。
* **审阅 frontmatter**：代码视图按源码原样显示 frontmatter（行号与文件一致）；MD 视图在正文前内联渲染元数据块，随内容滚动、不再吸顶。

* **官方预览入口**：「审阅视图」按钮去掉品牌色方块，改成与旁边头部按钮同款的 ghost 图标按钮，图标按钮之间的间距等分。

* **审阅本轮基线**：改为按**审阅会话**保存——新开一个审阅会话自动以当时正文开始新一轮，刷新 / 重开同一 tab 仍保留本轮改动；移除让人困惑的「以当前为基线」按钮。
* **审阅引导气泡**：对话开始后自动隐藏，只作为空白会话的引导，不再一直挂在输入框下方。
* **审阅侧栏标记**：会话运行 / 待处理时笔记功能区 tab 图标标记也会显示（改到时间标签后），不用等运行结束。
* **MD / 代码切换**：改成与顶栏 ghost 按钮一致的外形（透明底 + 发丝描边、同高），标签水平垂直居中。

* **审阅底栏**：两枚 split 按钮放大到 36px、离底边 18px；正文滚到按钮下方并在底部渐隐到面板底色（同官方 @ / 列表底部）；箭头菜单改为同款白色模糊玻璃并从按钮上方弹出，不再挡按钮；按钮改用官方主按钮材质，不再自绘玻璃，和官方白色按钮一致。

* **审阅底栏**：底部改为两枚 split 按钮——官方主按钮填充（深色主题近白底 + 深色字）、`提交批注`＋箭头（菜单里是批注草稿）、`本轮改动`＋箭头（菜单里是批注记录）；玻璃只画在整组上，无遮挡底条、不依赖 theme-tone；正文滚到按钮下方，浮层与按钮留 4px 间距。

* **审阅底栏**：玻璃只画在每枚胶囊自身的伪元素里（更低不透明度，无任何整条底衬）；点开的浮层底边与胶囊之间留出 12px，不再贴着胶囊。

* **审阅底栏**：三枚胶囊在面板变窄时可收缩，文字用省略号截断、悬停显示完整读数（与官方胶囊一致），不再挤出面板（窄于 430px 时同时收紧间距与内边距）。

* **审阅会话侧栏标记**：审阅流程打开的会话在左侧栏标题前显示笔记功能区 tab 的图标，标记持久化在宿主存储里（刷新 / 重启后仍在），一眼能看出哪些是审阅会话。

* **审阅批注记录**：审阅页底部新增第三枚胶囊，显示「批注记录 R 轮 / M 条」（轮次与批注条数分开，避免把 2 轮 3 条误读成 2 条），点开按当前文件列出已提交记录（时间、条数、引用与意见），提交批注后自动刷新。

* **审阅提示气泡**：从输入框上方移到**输入框下方**（空白会话与对话已开始后一致，输入框始终保留）；不再压住侧栏边线。

* **审阅底栏**：两枚胶囊用官方 Pill 形状 + 自包含玻璃（半透明层 + backdrop blur + 发丝边框，不依赖 theme-tone；不支持 blur 时回退实色），浮在正文底部，不占单独一行、也不需要遮挡底条。
* **会话列表**：整页宽度、分组卡片、组头（标题 + 数量）、行内 34% 固定标题列全部对齐笔记列表（8px 圆角、发丝边框、7px/10px 组头），去掉外层彩色描边区块。

* **笔记首屏**：首次加载完成前显示加载态，不再先闪一下「未链接」空页。

* **审阅版面**：frontmatter 默认折叠为一行元数据（点开再看全部）；底部两枚胶囊区高度 34→28px、滚动内容底部留白收紧，正文区更大。
* **审阅浮层**：底部两枚胶囊打开后的浮层改用官方标题区（图标 + 标题 + 操作），标题区固定不滚动，内容区独立滚动；长 diff 不再把标题带着一起滚。

* **笔记列表**：每页从 10 条改为 20 条，大屏上列表更饱满。

* **自适应与审阅细节**：日程顶部三卡随面板宽度重排（窄面板两列 / 单列），并与下方日历统一最大宽度 1100px；笔记页搜索框与视图 tab 随宽度换行、内容宽度上限放宽；审阅页 MD / 源码上方显示 frontmatter 元数据块。
* **审阅基线与对话提示**：轮次基线从浏览器 localStorage 移到宿主 `desk_one` 存储域（清浏览器缓存不丢，1MB 上限（与可审阅文件上限一致）；刷新或重开 tab 仍能看到本轮改动）；审阅会话的对话区输入框上方显示 AI 气泡「请您开始审阅吧，我在这里等您的意见」，只在审阅会话出现；文案现改为分两行的操作引导「选中右栏内的文本，点击 [批注]，开始审阅；[提交批注] 后我在这边修订。」，其中 [批注] / [提交批注] 渲染为内联小框。

* **日程同步错误**：同步失败不再在日程页显示错误；顶栏「日历设置」出现红色感叹号，点进去在对应来源卡片看具体错误，状态点红（来源失败）/ 黄（部分日历失败）。

* **审阅命名与工具条**：右侧栏 tab 改回「笔记审阅」，官方预览头部入口改为「审阅视图」；单条仍叫「批注」。MD / 代码 切换胶囊压到 28px、与复制 / 刷新等工具按钮同高；浮动「批注」按钮 hover 保持品牌蓝并加深（不再变白），与输入框发送按钮一致；右侧「笔记审阅」tab 标题前加了彩色 Markdown 文件图标。

* **侧栏入口**：默认仍只有一个「同桌」入口；每个 tab 头部新增「**添加到左栏**」按钮（tab 行末尾，未固定空心图钉 / 已固定实心图钉），可把该 tab 变成独立入口，再点「**移出左栏**」移除，入口即时增删并持久化（默认不拆开）。tab 文字前也加了图标（日程用自绘小日历，避免与官方自动化任务的时钟重复）。

* **Agent 能力**：随包一个 `desk-one` 操作指南 skill（默认开启，模型与 `/` 均可用），说明对象选择、`list → revision → update` 流程与归档/删除的连带影响；agent 工具保持显式动作（19 个，含只读笔记页检索 `desk_page_list`），不合并成通用 save。

* **笔记**：入口页与批注页继续收口。顶栏顺序改为「新建笔记」(primary) →「打开文件浏览」→「断开「<工作区名>」链接」（用真实工作区名，不再藏进 `⋯`）；篇数移到列表卡片顶部（共 N 篇，与翻页一致）；批注记录可点开只读详情，原文找不到只提示「原文可能改路径了」；缺元数据视图有 frontmatter 解释；空草稿不再被计为「有批注草稿」，提交后自动清掉草稿壳。批注页顶部视图切换为 MD / 代码 两档胶囊，底部两枚胶囊居中、透明底并加发丝线，浮层换成官方菜单面；只显示「批注」浮钮时点其它位置也会取消选中；官方预览头部「批注视图」按钮改为与相邻头部按钮同款的 ghost 图标按钮。会话页列表与笔记页统一行高 / 徽标 / 动作规格。笔记技能选择改为按默认预设 scope 读取（与官方 / 技能菜单一致），默认不用；列表只显示「笔记 / 写作技能」（`/` 里可调用且与笔记写作相关的技能），不再列出模型专用 agent 技能与自带 desk-one 指南。

## [0.2.2-rc.1] - 2026-11-06

* 首个版本：左侧栏多一个 **同桌**（Desk One）入口，面板内以标签页组织功能；顶部标签按 日程 / 便签 / 任务 / 笔记 / 会话 排列：**日程** 在前，**笔记** 预留为后续内容（本版空白）。
* 便签墙：点顶栏 **随手记** 或双击墙面空白处即可贴一张，新便签落在点击位置、显示在最上层并自动获得焦点；便签墙改为**固定宽度、纵向无限**的可滚动画布（拖动时便签严格跟手、不自动滚墙；墙面可滚到屏幕下方，双击整个滚动区都能新建）；顶栏按官方对话区重做：76px 紧凑顶栏（默认实色，theme-tone 开启时才玻璃），第一行品牌标题 + 一行小字说明和功能动作，第二行官方纯文字标签，末尾带官方省略号 More 按钮（内容自适应模糊菜单，当前显示「更多功能开发中…」，留给未来溢出页面）；顶栏是固定 76px 浮层，各功能首屏从下方开始、滚动内容从玻璃下经过；便签墙只在真正溢出时出滚动条，任务板与顶栏留 14px 间距；空墙中央有很淡的两行提示。直接在贴纸上写、按住正文在可见区域内拖动摆放（不出现滚动条），点过或拖过哪张哪张置顶，拖右下角可以改大小（最小 152×100，保证工具条始终在便签内），悬停可用垃圾桶图标丢进垃圾桶；每张便签底部以极低对比度显示本地创建日期（悬停看完整时间）；贴纸是平涂方角纸片，纸面取 Notion 深色色标的同色相中深色（色标再深一档、无渐变），文字、位置、尺寸、层级与垃圾桶状态都按便签保存并经官方 DSH 存储域持久化；顶栏垃圾桶入口可以恢复或永久删除，清空垃圾桶需要用户显式二次确认（不自动清空）。
* 任务板：固定三泳道看板（**待办 / 进行中 / 完成**），卡片带颜色标签（叠放色卡打开五色板直选）、标题与描述自动换行、按天截止日期（日历图标 + 日期，未设置仅图标）（逾期红字、只剩一天时琥珀色描边）、整卡指针拖拽（单击文字进编辑、按住任意其它位置即可拖，直立跟手副本、无效落点飞回原位），拖动时目标泳道 / 分组高亮并带插入线、泳道内双击新建、完成列可折叠、顶栏的「新建任务 / 排序下拉 / 存档」动作 + 三种视图（手动 / 创建时间 / 截止日期），以及 **存档**（仅完成列卡片可存档，可恢复或永久删除）。泳道排序改为**统一块序列**：未分组卡片与分组块可以在同一条手动序列里任意穿插，分组可以拖到卡片之间。每个泳道支持一层**持久化分组**（可以一直为空）：新建 / 就地改名 / 折叠 / 拖手柄排序 / 删除（卡片回到未分组），卡片可拖入或拖出。整组拖动与拖卡片一致：整块跟着鼠标，拖到其它泳道直接连卡片一起移动，没有二次确认。完成列的分组可以整组存档：存档视图按一条分组条目展示，恢复时整组与卡片一起回来，删除存档分组会连卡片一起彻底删除。任务卡可用 @ 关联一个或多个 DSH 会话（一个会话也可服务多张卡）：chip 用颜色区分状态（可用 = 绿、已归档/不可用 = 中性灰），运行中的会话多一圈缓慢旋转的绿环（减弱动态效果下静止），点 chip 在原位展开（最多占满卡片宽度、允许卡片增高；运行中边框动效跟随扩展后的 chip），显示上次运行、模型用时、轮数、步数、Token 用量；点其他位置立刻恢复，点箭头才跳转；关联不会覆盖卡片自己的文字。@ 入口单独一行、位于已关联 chip 下方；选择器是页面级浮层（不会被泳道裁切），列出与输入框 @ 同一份会话（含子代理会话）。面板变窄时三泳道收成只显示条数的窄列，不出现横向滚动条；泳道内容纵向溢出时显示细滚动条而不是压缩卡片，分组头改为两行（名称 + 计数），窄泳道里不再挤爆。泳道标题改为紧凑的英文大写品牌标签（加粗 + 字距，中文不受大写影响）；计数显示为「3 项」这类带单位文案，不再是裸数字。便签与任务板共用同一个两行顶栏和同一套按钮样式；对象级操作仍留在卡片/泳道上。`desk_task_*` agent 工具读写同一批任务。
* **日程** 标签：只读聚合企业微信 / iCloud CalDAV、任意公开 ICS 订阅；Outlook 个人账户走 Graph 设备码 OAuth（多日历、可写权限已申请），不再使用公开 ICS。日程页上排为三列：最左「开始」卡竖排 + 便签 / + 任务 / + 笔记 三个窄高白色主按钮（+ 笔记禁用占位），中间今日卡、右侧近期卡等宽并整体居中，上排高度降到 136px；今日与近期都把日期／日期区间放到标题同一行，进一步让出纵向空间；今日左右分栏（淡分割线）：左列今天的日程、右列日程 / 便签 / 未完成任务 / 活跃会话四枚彩色数字可点计数（点「N 个日程」跳到完整日历列表，接替被去掉的「查看完整日程」），两栏顶部对齐；近期上方为 1–14 天滑杆，已选区间高亮，去掉了「查看完整日程」按钮；会话页删除确认可一键复制标题、删除后列表不再闪烁，同步与「日历设置」入口改为同桌统一顶栏动作，下方为月历 / 周历 / 日（月历默认、周一起始、5–6 行自适应；周历左上角显示 ISO 周序号（`W46`）、左侧新增 0–24 小时时间轴，一屏 8 小时、默认锚定当前时间可滚动）；事件在点击位置附近弹卡片，显示 provider · 账号 · 日历，点其它区域或 Esc 关闭；完整连接与日历管理在「管理」子页面；管理页每个源合并为一张卡（绿点=已配置、灰点=未配置；连接设置默认收起，具体日历在源卡内逐本控制同步/显示），关闭同步会停止拉取并清空该日历的本地镜像（用于清理客户端已看不到的遗留日历）。打开面板自动同步、之后每 15 分钟一次；凭据只进官方凭据库。日历设置 / 便签垃圾桶 / 任务存档三个子页统一标题、统计与字号排版，返回按钮一律放顶栏右侧；手动同步移到日历设置子页页头；今日卡日期带星期，日程范围文字居中，近期滑杆已选区间高亮；清空垃圾桶的确认态点旁边或按 Esc 可取消。
