# 更新日志

[English](CHANGELOG.md) | 简体中文

`dsh-desk-one` 的所有用户可感知变化都记在这里。格式遵循 Keep a Changelog，版本号跟随官方 DSH 发布线。

## [0.2.2-rc.5.1] - 2026-11-22

- 任务捕获现在把项目和代码工作也当作任务：只要请求有明确的落地结果——改文件、改代码 / 配置 / 数据 / 文档、交付物、验收或后续跟进——Desk One 会问一次是否建卡并挂上本会话。它会在第一条真正开始做事的请求时判断，工作后来变成多步任务时可再问一次；仍然不会静默建卡或挂会话。
- 当你明确要求时，助手现在可以永久删除任务卡；只删卡片，不动关联会话和分组。

## [0.2.2-rc.5] - 2026-11-22

- 任务卡描述默认收起为一行，点击展开；整卡可收起为 compact 行，保留标题、颜色、截止日期和已挂会话数量；两种状态跨刷新保留。
- 任一会话运行中时，整张任务卡按卡片自己的颜色显示运行环，归档行和会话 chip 同样提示；运行环作为状态提示始终旋转。
- 新会话任务捕获现在会在首条消息像跟踪事项时先问一次，先查本会话是否已有关联任务，已有未挂任务时先问补挂，不静默建卡或改关联。
- 任务卡支持按当前会话过滤、补挂当前会话，或解绑某个会话。
- 一并发布此前未发版改进：归档区刷新与两步确认、会话彻底删除二次确认、会话列表分页/排序/时间显示、便签与任务统一五色板。
- 审阅默认在当前会话打开；「在新会话审阅」作为显式次入口。打开审阅视图本身不再标记会话，首次保存批注或显式新开会话才标记；会话徽标可点击清除误标记。
- 「和我说」菜单里的每条建议都加上双引号，列表读起来像在说话。
- 页头与各功能页现在共用一致的内容宽度，页面内容和「Pin to sidebar」快捷入口保持对齐；批注页使用完整内容宽度。
- 批注输入框只能通过「取消」关闭：点外部或按 Esc 都不再关闭，空内容也不关；有内容时首次点「取消」需要二次确认，空内容一次即关；打开期间不能直接替换成另一处批注。
- 桌面端 Microsoft 登录现在能正确回到 Desk One，不再停在失败的回调页；成功页也不再跳回登录页。
- 适配官方 dsh 0.2.2-rc.5（Web 与桌面端）；官方 web search 默认变化不影响本插件。
