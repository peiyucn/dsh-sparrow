# 更新记录

[English](CHANGELOG.md) | 简体中文

`dsh-desk-one` 的用户可感知改动都记在这里。格式遵循 Keep a Changelog，版本号与官方 DSH 发布线保持一致。

## [0.2.2-rc.1] - 2026-11-06

* 首个版本：左侧栏多一个 **同桌**（Desk One）入口，面板内以标签页组织功能；顶部标签按 日程 / 便签 / 任务 / 笔记 / 会话 排列：**日程** 在前，**笔记** 预留为后续内容（本版空白）。
* 便签墙：点顶栏 **随手记** 或双击墙面空白处即可贴一张，新便签落在点击位置、显示在最上层并自动获得焦点；便签墙改为**固定宽度、纵向无限**的可滚动画布（拖动时便签严格跟手、不自动滚墙；墙面可滚到屏幕下方，双击整个滚动区都能新建）；顶栏按官方对话区重做：76px 紧凑顶栏（默认实色，theme-tone 开启时才玻璃），第一行品牌标题 + 一行小字说明和功能动作，第二行官方纯文字标签，末尾带官方省略号 More 按钮（内容自适应模糊菜单，当前显示「更多功能开发中…」，留给未来溢出页面）；顶栏是固定 76px 浮层，各功能首屏从下方开始、滚动内容从玻璃下经过；便签墙只在真正溢出时出滚动条，任务板与顶栏留 14px 间距；空墙中央有很淡的两行提示。直接在贴纸上写、按住正文在可见区域内拖动摆放（不出现滚动条），点过或拖过哪张哪张置顶，拖右下角可以改大小（最小 152×100，保证工具条始终在便签内），悬停可用垃圾桶图标丢进垃圾桶；每张便签底部以极低对比度显示本地创建日期（悬停看完整时间）；贴纸是平涂方角纸片，纸面取 Notion 深色色标的同色相中深色（色标再深一档、无渐变），文字、位置、尺寸、层级与垃圾桶状态都按便签保存并经官方 DSH 存储域持久化；顶栏垃圾桶入口可以恢复或永久删除，清空垃圾桶需要用户显式二次确认（不自动清空）。
* 任务板：固定三泳道看板（**待办 / 进行中 / 完成**），卡片带颜色标签（叠放色卡打开五色板直选）、标题与描述自动换行、按天截止日期（日历图标 + 日期，未设置仅图标）（逾期红字、只剩一天时琥珀色描边）、整卡指针拖拽（单击文字进编辑、按住任意其它位置即可拖，直立跟手副本、无效落点飞回原位），拖动时目标泳道 / 分组高亮并带插入线、泳道内双击新建、完成列可折叠、顶栏的「新建任务 / 排序下拉 / 存档」动作 + 三种视图（手动 / 创建时间 / 截止日期），以及 **存档**（仅完成列卡片可存档，可恢复或永久删除）。泳道排序改为**统一块序列**：未分组卡片与分组块可以在同一条手动序列里任意穿插，分组可以拖到卡片之间。每个泳道支持一层**持久化分组**（可以一直为空）：新建 / 就地改名 / 折叠 / 拖手柄排序 / 删除（卡片回到未分组），卡片可拖入或拖出。整组拖动与拖卡片一致：整块跟着鼠标，拖到其它泳道直接连卡片一起移动，没有二次确认。完成列的分组可以整组存档：存档视图按一条分组条目展示，恢复时整组与卡片一起回来，删除存档分组会连卡片一起彻底删除。任务卡可用 @ 关联一个或多个 DSH 会话（一个会话也可服务多张卡）：chip 用颜色区分状态（可用 = 绿、已归档/不可用 = 中性灰），运行中的会话多一圈缓慢旋转的绿环（减弱动态效果下静止），点 chip 在原位展开（最多占满卡片宽度、允许卡片增高；运行中边框动效跟随扩展后的 chip），显示上次运行、模型用时、轮数、步数、Token 用量；点其他位置立刻恢复，点箭头才跳转；关联不会覆盖卡片自己的文字。@ 入口单独一行、位于已关联 chip 下方；选择器是页面级浮层（不会被泳道裁切），列出与输入框 @ 同一份会话（含子代理会话）。面板变窄时三泳道收成只显示条数的窄列，不出现横向滚动条；泳道内容纵向溢出时显示细滚动条而不是压缩卡片，分组头改为两行（名称 + 计数），窄泳道里不再挤爆。泳道标题改为紧凑的英文大写品牌标签（加粗 + 字距，中文不受大写影响）；计数显示为「3 项」这类带单位文案，不再是裸数字。便签与任务板共用同一个两行顶栏和同一套按钮样式；对象级操作仍留在卡片/泳道上。`desk_task_*` agent 工具读写同一批任务。
* **日程** 标签：只读聚合企业微信 / iCloud CalDAV、任意公开 ICS 订阅；Outlook 个人账户走 Graph 设备码 OAuth（多日历、可写权限已申请），不再使用公开 ICS。日程页上排为三列：最左「开始」卡竖排 + 便签 / + 任务 / + 笔记 三个窄高白色主按钮（+ 笔记禁用占位），中间今日卡、右侧近期卡等宽并整体居中，上排高度降到 136px；今日与近期都把日期／日期区间放到标题同一行，进一步让出纵向空间；今日左右分栏（淡分割线）：左列今天的日程、右列便签 / 未完成任务 / 活跃会话三枚彩色数字可点计数，两栏顶部对齐；近期上方为 1–14 天滑杆，已选区间高亮，去掉了「查看完整日程」按钮；会话页删除确认可一键复制标题、删除后列表不再闪烁，同步与「日历设置」入口改为同桌统一顶栏动作，下方为月历 / 周历 / 日（月历默认、周一起始、5–6 行自适应；周历一屏 8 小时、默认锚定当前时间可滚动）；事件在点击位置附近弹卡片，显示 provider · 账号 · 日历，点其它区域或 Esc 关闭；完整连接与日历管理在「管理」子页面；管理页每个源合并为一张卡（绿点=已配置、灰点=未配置；连接设置默认收起，具体日历在源卡内逐本控制同步/显示），关闭同步会停止拉取并清空该日历的本地镜像（用于清理客户端已看不到的遗留日历）。打开面板自动同步、之后每 15 分钟一次；凭据只进官方凭据库。日历设置 / 便签垃圾桶 / 任务存档三个子页统一标题、统计与字号排版，返回按钮一律放顶栏右侧；手动同步移到日历设置子页页头；今日卡日期带星期，日程范围文字居中，近期滑杆已选区间高亮；清空垃圾桶的确认态点旁边或按 Esc 可取消。
* **会话** 标签：活跃会话按工作区分组；四个分区（活跃 / 归档 / 游离 / 回收站）统一行布局与图标操作，活跃区绿色柔和描边、其余灰色；父子会话用嵌套分组显示，操作只挂在父行、子会话完全跟随；活跃行只提供轻归档（不碰文件），移入回收站 / 删除留在归档区与回收站；归档区可取消归档、移入回收站或彻底删除（父会话与子会话一起处理）；游离会话单独列出，可归档 / 回收站 / 删除；回收站可展开父子、单个或全部还原、彻底删除，并显示可复制的路径。彻底删除普通会话要输入完整标题确认，空白会话与批量操作各有二次确认。各分区每页 30 条「加载更多」；父行统一显示「N 子会话」，子行统一标「子会话」。原独立归档插件的文件级管理能力已迁入这里。
* 容量与止损：便签墙上限 **100** 张、垃圾桶上限 **200** 张；垃圾桶一次渲染 10 行，顶部显示总数并带「加载更多」，垃圾桶按钮不再挂计数角标。**Smash!** 是顶栏里常驻的危险色动作按钮——二次确认后把整墙便签扔进垃圾桶并带一段飞散动画；确认态下点击别处或按 **Esc** 会取消。垃圾桶入口和墙面动作在同一排顶栏里，提示为「打开垃圾桶」；单张贴纸丢进垃圾桶也播同一段动画。
* Agent 工具（`desk_note_*`）读写同一批便签；离开同桌再回来会停在上次所在的标签页。
