## [0.2.2-rc.1] - 2026-11-06

* 首个版本：左侧栏多一个 **办公桌** 入口，面板内以标签页组织功能；**总览** 预留为后续的聚合中心，本版保持空白。
* 便签墙：点右下角悬浮的 **＋** 或双击墙面空白处即可贴一张，新便签落在点击位置、显示在最上层并自动获得焦点；两个悬浮按钮位于底部中央，是磨砂玻璃材质、打光方向和主题化的输入框一致；空墙中央有很淡的两行提示。直接在贴纸上写、按住正文在可见区域内拖动摆放（不出现滚动条），点过或拖过哪张哪张置顶，拖右下角可以改大小，悬停可用垃圾桶图标丢进垃圾桶；贴纸是平涂方角纸片，纸面取 Notion 深色色标的同色相中深色（色标再深一档、无渐变），文字、位置、尺寸、层级与垃圾桶状态都按便签保存并经官方 DSH 存储域持久化；与 **＋** 成组的垃圾桶入口可以恢复或永久删除，清空垃圾桶需要用户显式二次确认（不自动清空）。
* 任务板：固定三泳道看板（**待办 / 进行中 / 完成**），卡片带颜色标签（叠放色卡打开五色板直选）、标题与描述自动换行、按天截止日期（日历图标 + 日期，未设置仅图标）（逾期红字、只剩一天时琥珀色描边）、整卡指针拖拽（单击文字进编辑、按住任意其它位置即可拖，直立跟手副本、无效落点飞回原位），拖动时目标泳道 / 分组高亮并带插入线、泳道内双击新建、完成列可折叠、手动 / 创建时间 / 截止日期三种视图，以及 **存档**（仅完成列卡片可存档，可恢复或永久删除）。泳道排序改为**统一块序列**：未分组卡片与分组块可以在同一条手动序列里任意穿插，分组可以拖到卡片之间。每个泳道支持一层**持久化分组**（可以一直为空）：新建 / 就地改名 / 折叠 / 拖手柄排序 / 删除（卡片回到未分组），卡片可拖入或拖出。整组拖动与拖卡片一致：整块跟着鼠标，拖到其它泳道直接连卡片一起移动，没有二次确认。完成列的分组可以整组存档：存档视图按一条分组条目展示，恢复时整组与卡片一起回来，删除存档分组会连卡片一起彻底删除。任务卡可用 @ 关联一个或多个 DSH 会话（一个会话也可服务多张卡）：chip 用颜色区分状态（可用 = 绿、已归档/不可用 = 中性灰），运行中的会话多一圈缓慢旋转的绿环（减弱动态效果下静止），点 chip 打开会话，关联不会覆盖卡片自己的文字。@ 入口单独一行、位于已关联 chip 下方；选择器是页面级浮层（不会被泳道裁切），列出与输入框 @ 同一份会话（含子代理会话）。面板变窄时三泳道收成只显示条数的窄列，不出现横向滚动条；泳道内容纵向溢出时显示细滚动条而不是压缩卡片，分组头改为两行（名称 + 计数），窄泳道里不再挤爆。泳道标题加大加粗并改用官方品牌蓝紫色；计数显示为「3 项」这类带单位文案，不再是裸数字。`desk_task_*` agent 工具读写同一批任务。
* 容量与止损：便签墙上限 **100** 张、垃圾桶上限 **200** 张；垃圾桶一次渲染 10 行，顶部显示总数并带「加载更多」，垃圾桶按钮不再挂计数角标。**Smash!** 是 **＋** 旁边常驻红色的磨砂玻璃图标按钮——二次确认后把整墙便签扔进垃圾桶并带一段飞散动画；确认态下点击别处或按 **Esc** 会取消。垃圾桶入口用一条细分隔线与墙面操作隔开，提示为「打开垃圾桶」；单张贴纸丢进垃圾桶也播同一段动画。
* Agent 工具（`desk_note_*`）读写同一批便签；离开办公桌再回来会停在上次所在的标签页。
