# 更新日志

[English](CHANGELOG.md) | 简体中文

`dsh-desk-one` 的所有用户可感知变化都记在这里。格式遵循 Keep a Changelog，版本号跟随官方 DSH 发布线。

## [0.2.2-rc.3] - 2026-11-14

* **首发 —— 同桌（Desk One）**：左侧栏一个「同桌」入口，承载标签式面板（顺序：便签 / 任务 / 笔记 / 日程 / 会话）；每个 tab 可「固定到左栏」变成独立入口（即时增删、重启后保留），面板会记住上次所在的 tab。面板外观对齐官方对话区页头；只有启用 theme-tone 时才使用玻璃材质。

* **笔记**：把一个 DSH 工作区链接为笔记库，用四档视图（全部 / 批注草稿 / 批注记录 / 缺元数据）浏览与搜索库内 Markdown / 文本页；可「创建空文件」，也可「让 AI 起草」（笔记 / 写作技能可选、默认不用，只列出 `/` 里可调用的笔记类技能）。官方文件浏览与 markdown 预览保持原样。

* **和 DSH 一起**：页头常驻「✦ 和 DSH 说」入口，按当前 tab（便签 / 任务 / 笔记 / 日程 / 会话）给出预填提示；便签墙空态与任务空板也各有一个「让 DSH 记一条 / 建任务」入口。点选后在当前 / 最近工作区打开（或复用）空白会话，把半句指令追加进输入框草稿并聚焦，**不自动发送**；没有工作区时沿用官方提示。info 浮层改为「两种用法 + 示例」。日程与会话只提供只读 / 整理类提示，不给写入口。

* **审阅**：独立审阅 tab，源码带精确行号；选中行就地批注（可编辑 / 删除草稿），「提交批注」把编号批注插入该审阅会话的输入框（不自动发送），「本轮改动」按**审阅会话**基线与当前正文对比，并在代码视图里就地高亮改动行；已提交的批注记录可回看、可删除。再次打开同一篇笔记会复用该笔记仍可用的审阅会话（不占用你当前的会话）；审阅会话在侧栏有官方蓝色的图标标记（官方文件浏览头部的「审阅视图」入口同色），输入框内有操作引导。

* **便签墙**：自由摆放的便签画布——点「随手记」或双击空白处新建，就地编辑，可拖动 / 改大小 / 换颜色 / 调层级，每张显示创建日期。墙上限 100 张、垃圾桶 200 张；垃圾桶支持恢复与永久删除，**Smash!** 二次确认后把整墙清进垃圾桶。

* **任务板**：固定三泳道看板（待办 / 进行中 / 完成），支持颜色标签、按天截止日期、指针拖拽与精确插入线、手动 / 创建时间 / 截止日期三种排序、一层分组（可整组拖动、整组存档 / 恢复）与完成列存档。任务卡可用 **@** 关联 DSH 会话，chip 实时显示状态并支持就地预览。

* **日程**：只读聚合企业微信 CalDAV、iCloud CalDAV、Outlook 个人（Microsoft Graph 登录）与任意公开 ICS 订阅。上排是「开始 / 今日 / 近期」，下方是月历 / 周历 / 日历视图，点事件弹出详情卡片；顶栏「日历设置」进入按源管理页（手动同步、逐本日历显隐与颜色）。面板打开时同步、之后每 15 分钟一次；同步失败在「日历设置」入口显示徽标，并在对应来源卡里给出具体错误。

* **日程同步更稳**：过期的 Outlook 登录流程会自动清理，回调地址非法时会给出明确提示，同步报告只统计实际入库的日程数。

* **会话**：共享的 agent 会话目录——活跃会话按工作区分组，归档 / 游离 / 回收站分区支持取消归档、移入回收站、还原与彻底删除（删除普通会话需逐字输入标题确认），父子会话嵌套显示；每行可复制会话名称与会话 ID。

* **Agent 工具**：19 个 `desk_*` 工具（便签 / 任务 / 分组 / 日程 / 笔记页只读检索）与界面读写同一批数据；随包注册 `desk-one` 操作指南 skill（默认开启、`/` 里可用），讲清对象选择与 list → revision → update 流程。

* **日期与窄面板**：日期时间跟随界面语言（中文界面显示「11月13日」这类本地格式）；面板变窄时日程上排、笔记工具条与任务泳道会自适应重排，不出现横向溢出。

* **数据与隐私**：便签、任务、日程镜像与笔记审阅记录存在 profile 级 `desk_one` 存储域；日程凭据（同步密码 / OAuth refresh token / 订阅链接）只存官方凭据库，不写进日志、HTML 或导出文件。

* **归档走官方正路**：在 Desk One 里归档 / 取消归档会话，现在都委托官方归档 API——有进行中活动的会话会被拒绝并提示先停止生成，归档会同时摘掉 pin，官方后续动作（如 rc.2 起的 worktree 清理）与官方会话菜单完全一致。

* **笔记筛选标签**：英文界面下四个视图标签保持单行（文案缩短），在常规宽度面板里不再折成两行。

* **边栏快捷入口**：「固定在左栏」的入口（如会话）再次点击会回到它对应的标签页，即使此前在该面板里切过标签。

* **会话标签图标**：会话标签与（固定后的）左栏入口改用官方会话列表图标（带两行文字的气泡），不再与官方「新会话」按钮的图标重复。

* **已知限制**：日程只读（不支持本地事件创建、写回外部、把自己日历发布为 iCalendar 订阅源；订阅外部 ICS 已支持）。专注、跨对象搜索、数据导入导出与更丰富的任务字段在仓库 spec 中排期。
