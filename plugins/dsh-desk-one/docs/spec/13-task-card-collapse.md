# 13 · 任务卡折叠：描述收起 + 整卡收起

> 状态：**已实现（2026-11-19），待 owner 真机验收。**目标版本：**0.2.2-rc.5**（发布暂缓）。
> 来源：owner 新要求。只做单卡折叠，不做整个看板 / 泳道折叠。

## 决策（owner 已确认）

| # | 决策 | 取值 |
| :-- | :--- | :--- |
| 1 | 折叠范围 | 只做单张任务卡；不改泳道 / 看板 |
| 2 | 描述 | **默认收起**，只显示一行部分正文；可展开；空描述不显示折叠入口 |
| 3 | 整卡 | 默认展开，手动收起为 compact 态 |
| 4 | compact 保留 | 标题 + 颜色 + 截止日期 + **已挂会话数量**；不显示 chips；操作按钮悬停显示 |
| 5 | 持久化 | 按 task id 存 localStorage，跨刷新保留；不写任务记录、不涨 revision |
| 6 | 状态关系 | 整卡收起与描述收起相互独立；展开整卡不自动展开描述 |

## 数据与状态

- UI 状态只属于客户端，不进入 `DeskTask` / 存储域 / revision。
- localStorage key：`dsh-desk-one:task-card-state`。
- 值形状：

```ts
type TaskCardUiState = {
  card?: 'collapsed'
  body?: 'expanded'
}
type TaskCardUiStateMap = Record<string, TaskCardUiState>
```

- 默认：`card` 展开、`body` 收起。
- 读取失败 / JSON 损坏 / 非对象：当作空状态，不抛错。
- 写入失败（隐私模式、配额）：静默降级为当次会话内存状态，不影响任务数据。
- 任务删除后状态可保留但不再渲染；读取时忽略不存在的 task id；状态数超过 500 条时按最近写入淘汰（简单上限，避免无限增长）。

## 交互

### 描述收起

- 卡片展开时，描述区域只显示一行正文（CSS line-clamp 1 / 省略号）；默认收起。
- 描述非空时，body 行尾显示小型展开 / 收起按钮（`aria-expanded` + tooltip）；点击只切描述，不进入编辑。
- 描述收起时点击正文本身：展开描述（不进入编辑）。
- 描述展开后点击正文：进入原有编辑态，行为不变。
- 描述为空时：保留原有占位文案，不显示展开 / 收起按钮；点击仍进入编辑。
- 编辑态始终显示全文；失焦保存后按当前描述折叠状态渲染。
- 描述收起 / 展开状态跨刷新保留。

### 整卡收起

- 卡片右上角显示小型折叠按钮（悬停 / 聚焦可见；收起态始终可见）；点击只切整卡状态，不触发拖拽 / 编辑。
- compact 态下：
  - 标题单行省略；点击标题仍进入标题编辑（不展开卡）。
  - 保留左侧颜色条与截止日期（未设置则不显示日期）。
  - 若 `task.sessionIds.length > 0`，显示会话图标 + 数量（如 `2`，tooltip「已关联 2 个会话」）；不显示 chips、`@` 入口。
  - 悬停 / 聚焦时显示存档与删除操作；其它时间不占位。
  - 整卡仍可拖拽；折叠按钮、标题编辑、操作按钮不触发拖拽。
- 展开后恢复原来的描述折叠状态与完整内容。
- 整卡状态跨刷新保留。

### 边界

- 拖拽、点击编辑、描述展开、整卡折叠的 pointer 事件互不误触：折叠按钮与描述按钮 `stopPropagation`，且不进入拖拽起点。
- 归档视图复用同一张卡；折叠状态按 task id 生效。
- 卡片上的截止日期、颜色、会话数量是只读展示；要修改仍展开卡后操作。
- 不发新任务、不改任务字段、不触发 host 请求。

## 验收

1. 新卡默认：整卡展开、描述只显示一行；长描述省略，点击展开全文，再点进入编辑。
2. 描述为空：显示占位，不出现展开按钮；点击进入编辑。
3. 描述收起状态刷新后保留；展开后刷新仍展开。
4. 整卡点右上折叠 → 只剩标题 / 颜色 / 截止 / 会话数量（有会话时）；再点恢复完整卡。
5. compact 态拖拽正常；折叠按钮、标题、操作按钮不会误触发拖拽。
6. compact 态悬停出现存档 / 删除；无存档权限的卡不出现存档。
7. 整卡收起 / 展开不影响描述的展开状态。
8. 归档视图同样生效。
9. localStorage 损坏 / 不可写时不报错，任务功能不受影响。
10. 中英文文案齐全；`npm run verify` 全绿。

## 非目标

- 整个看板 / 泳道折叠（已有分组折叠，不改）。
- 把折叠状态写进任务记录或同步到多端。
- 自动按描述长度折叠（默认就是收起）。
- 在 compact 态直接改颜色 / 截止 / 挂会话。
- 新增拖拽手柄或改变现有拖拽语义。
