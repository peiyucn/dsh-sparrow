# 07 · 笔记（最小版）：AI 主写 + 人审阅

> 状态（2026-11-13）：**已实现**。取代此前被撤销的「笔记库 + 审阅会话」完整版。
>
> 定位：新建/维护笔记的入口与批注视图；**AI 主写、人审阅**；不做编辑器、不依赖 git、
> 不与官方 diff 审阅桥接。

## 1. 为什么是这个形态

官方「变更请求 → 本地变更」只在 **git 检出 + 有变更** 时可用，定位是「有改动后的评论」；
笔记场景多为：① 目录由网盘同步、没有 git；② 文档相对检出没有变化时官方视图无从开始；
③ 需要「AI 主写、人发起第一轮审阅」。因此保留笔记入口与批注视图，但不重建状态体系。

## 2. 实体与存储

| 实体 | 存哪 | 说明 |
|:--|:--|:--|
| 笔记库根 | `notebook-config` | 单个记录；指向一个已注册的 DSH 工作区目录 |
| 笔记索引 | **派生** | 扫描根的 `.md/.markdown/.txt`；标题/类型/日期/标签由 frontmatter 解析 |
| 文件身份 | `note-file` | **惰性分配**（首次审阅时）；路径 + 内容哈希；改名后按哈希重新关联 |
| 批注草稿箱 | `note-draft` | 每个文件身份一条；存尚未提交的批注 |
| 审阅历史 | `review-record` | 每次提交一条：会话 id + 文件快照元信息 + 批注；不存正文快照 |

审阅状态本身不落库：提交后的批注就是对话消息，另外按「独立审阅对象」留一份历史。

## 3. 入口页（管理面，不是浏览器）

浏览与阅读交给官方右侧栏文件浏览。**DSH 的右侧栏只在会话页存在**（面板页没有会话 surface，
`sidebarRight.openTab` 会拒绝），所以「中间留 Desk One、右边开官方文件树」在现版 DSH 做不到；
入口页提供两条进入审阅的路：① 搜索 / 最近列表里点某一篇 → 进入审阅会话；
② 显式点「打开文件浏览」→ 新开会话并打开官方文件页（此时切到会话页，之后在官方树里自选文件）。
进入审阅会话后，该会话的官方右侧栏文件树即成为浏览入口。官方目录树与官方预览我们不复制、不改动。
入口页本身只做（页面固定一屏高，列表在卡片内滚动）：

- **顶栏动作**（与其它标签一致：primary 在最左、其次工具动作；不把常用动作藏进菜单）：
  「新建笔记」（primary）·「打开文件浏览」·「断开「<工作区名>」链接」（用真实工作区标题）；
- **新建**：展开一段话输入（标题、给谁看、大概包含什么），两个出口：「创建空文件」（第一行作标题）
  /「让 AI 起草」（整段作为预填 prompt）；不再单独写标题字段、不弹窗；
- **笔记技能**：新建区一行「技能：note2md ⓘ 更换」；ⓘ 解释 note2md 是什么；选择来自**默认 agent preset 的
  scope**（与官方 / 技能菜单、命令面板一致，因为新建/批注都会开新会话），可选默认 note2md、任意已装技能或
  「不使用」。选择只写进新会话的预填 prompt，**不注入上下文**；技能文件由宿主监视，新增/修改技能无需重启 DSH；
- **搜索**：工具条里的官方 `Input`（搜索图标、跨库检索，作用于当前视图）；
- **视图**：官方 `SegmentedTabs` 四档——全部 / 批注草稿 N / 批注记录 N / 缺元数据 N；
  行内徽标写作「批注草稿 N」「批注记录 N」「缺元数据」，不再用裸「草稿」；
  「缺元数据」视图顶部一行灰字解释 frontmatter 是什么；
- **列表**：与会话页同款紧凑单行行高（32px、13px 标题、11px 次级信息、l1 发丝分隔），
  标题列固定宽度、路径列对齐；卡片顶部一行计数（共 N 篇 / 各视图各自条数）；
  默认每页 **10 条**，底部「第 x / y 页」翻页；
- **批注记录**：点一条记录打开只读详情（官方 `Modal`）：文件、时间、批注列表；
  原文找不到时只提示「原文可能改路径了」，不展示「关联 / 改名 / 脱钩」这类概念；可删除记录、
  能解析原文时可直接打开原文；
- **未链接**：不放标题与说明——两个按钮就是指引（链接已有工作区 / 新建工作区…）；按钮下发丝分割线，
  其下两行灰色小字写清「笔记库是什么」与「只索引目录内 md/文本文件」（顶栏动作此时隐藏）。

### 3.1 官方预览头部的「批注视图」入口

- 官方文件浏览与文档预览**一行不改**；通过公开槽 `sidebar.right.tab.document.actions`
  在官方预览头部为笔记库内 md/markdown/txt 增加一个**文件+笔图标、官方 Button primary 规格（28px 方形、品牌色）**的按钮；
- 点击 = 在笔记库工作区新建审阅会话并打开批注视图（默认源码视图）；官方预览不切模式、不注入 DOM；
- 库外文件不出现该按钮；其它工作区不受影响。
## 4. 批注视图与入口

- **官方预览入口**（推荐路径）：官方文件浏览/文档预览完全不动；笔记库内的 md / markdown / txt
  在官方预览头部多一个「批注视图」按钮（公开槽 `sidebar.right.tab.document.actions`，
  `canOpen` 以「文件在笔记库根内」为界）。点击 = 在笔记库工作区**新建审阅会话**并在其中打开
  我们的批注 tab（默认源码视图）；官方预览本身不切模式、不注入 DOM，与官方行为互不影响；
- 面板入口：笔记页点一篇 → **在笔记库所属工作区新建会话**（官方 `startSession`）→ 右侧栏打开批注 tab；
  不借用用户当前会话；
- **视图切换**：「源码」（默认）/「渲染」；
  - 源码视图：每行行号 + 源文本；选中行后浮出小按钮「批注」（沿用面板按钮样式），点击才弹
    输入框；输入框**就地渲染在选中行下方**并自动聚焦；保存的批注锚定**精确行号区间 + 引用文本**，
    高亮对应行并在行下就地显示卡片；
  - 取消联动：Esc、点输入框外、点「取消」都会关闭输入框并同时清掉选中高亮与浏览器原生选区；
    **只显示「批注」浮钮、尚未输入时**，点页面其它任何位置也会取消选中，不会留下无法退出的高亮；
  - 输入框**必须留在选中行下方**（静态文档流），不得绝对定位到面板底部；结构测试有守卫；
  - 输入框与已保存批注**同槽位同视觉**：相同的左缩进（对齐行号右侧）、相同的品牌色左竖线，
    先输入、保存后原位变成批注卡片；
  - 渲染视图：只读阅读；批注请在源码视图操作；
- 顶部「整篇批注」：范围为整篇，引用用标题；
- 顶部工具条：**官方组件**——`源码 / 渲染` 用官方 `SegmentedTabs`（sm），复制路径 / 刷新用官方
  Button ghost + Tooltip，整篇批注用官方 outline Button；
- 底部固定菜单：**官方 composer 胶囊**（官方 `Pill`）——透明底、左侧拖拽条上方一条发丝分隔线、
  两枚胶囊**居中**：`批注草稿 N 处` 与 `本轮改动 +A −D`（无改动显示「持平」），点开为浮层；
  浮层用官方菜单面（menu surface token + 圆角 + elevation），提交 / 收起用官方 Button；
- 视觉规范：入口页、批注 tab、官方预览按钮统一用官方主题 token 与官方基础组件
  （Button / Input / SegmentedTabs / Pill / Tag / Modal），不自造按钮/胶囊样式；
  官方预览头部的「批注视图」按钮用品牌色填充（`state-business-primary`），深色主题下不再变白块。
- 「本轮改动」= tab 打开时正文 vs 当前正文（官方 DiffBlock，默认收起）；可见时静默刷新；
- 「提交批注」：按编号插入新会话输入框（不自动发送），格式：

```
【批注 1】文件：Diary/x.md
行号：42-44
> 引用原文
意见：…
```

同时写入一条 `review-record` 批注记录并清空批注草稿箱。

## 5. 官方文件浏览的复用边界

- **不动**官方文件页与文档预览：不注册地址接管、不替换渲染器、不注入 DOM；
- 复用公开槽给官方预览头部加一个按钮；文件导航继续用官方目录树（预览头部的目录树按钮）；
- 入口页**不自建目录树**：整棵树只在官方文件页里浏览；入口页列表只是分页的全部 / 记录视图；

## 6. 非目标

- 不做编辑器（0→1 在对话里完成）；不依赖 git、不桥接官方 diff；
- 不做轮次快照/历史 diff/接受状态/失效锚点/随包 skill；
- 不做笔记同步/备份/加密；渲染视图不承载批注交互。

## 7. 验收标准

1. 未链接时画面中央只有两个按钮（链接已有工作区 / 新建工作区…），说明与灰色提示都在发丝分割线下面，
   顶栏动作隐藏；
2. 链接后顶栏依次为「新建笔记」（primary）「打开文件浏览」「断开「<工作区名>」链接」（用真实工作区名，
   不藏进菜单）；列表卡片顶部显示「共 N 篇」（各视图显示各自条数），与翻页总数对得上；
3. 笔记页固定一屏高，不出现整页滚动条；列表与会话页同款紧凑行，每页 10 条、底部可翻页；
   四档视图（全部 / 批注草稿 / 批注记录 / 缺元数据）可切换，缺元数据行有徽标，该视图顶部解释
   frontmatter 是什么；
4. 批注记录行可点击打开只读详情（文件、时间、批注列表）；原文找不到时只提示「原文可能改路径了」，
   界面不出现「关联 / 改名 / 脱钩」这类概念；能解析原文时可直接「打开原文」或删除记录；
5. 笔记库内 md 在官方预览头部出现**品牌色**「批注视图」按钮（深色主题不是白色方块），点击后新开
   审阅会话并显示源码视图；笔记库外的文件不出现该按钮；官方预览行为不变；
6. 点笔记 → 在库工作区新开会话并打开审阅；无工作区时给出明确提示；
7. 源码视图行号精确；选中 → 小按钮 → 行下输入框（自动聚焦）；批注高亮+就地展示；可切「渲染」
   只读视图；**仅显示「批注」浮钮时点其它位置也会取消选中**；
8. 批注页术语与入口页一致：批注草稿 / 批注记录 / 批注；「提交批注」后输入框出现编号批注
   （含精确行号），批注记录出现对应条目；顶部工具条、图标动作、底部胶囊、浮层都用官方组件与
   主题 token（底部胶囊居中、浮层是官方菜单面）；
9. 会话页列表与笔记页同款：32px 单行行高、13px 标题、11px 次级信息、同规格徽标与动作按钮；
10. 改文件后「本轮改动」可见；批注记录可删除、占用超限红框提示；
11. `npm run verify` 与根 `check` 全绿。
