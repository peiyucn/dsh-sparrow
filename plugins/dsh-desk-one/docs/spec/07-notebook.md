# 07 · 笔记（最小版）：AI 主写 + 人审阅

> 状态（2026-11-12）：**已实现**。取代此前被撤销的「笔记库 + 审阅会话」完整版。
>
> 定位：新建/维护笔记的入口与审阅视图；**AI 主写、人审阅**；不做编辑器、不依赖 git、
> 不与官方 diff 审阅桥接。

## 1. 为什么是这个形态

官方「变更请求 → 本地变更」只在 **git 检出 + 有变更** 时可用，定位是「有改动后的评论」；
笔记场景多为：① 目录由网盘同步、没有 git；② 文档相对检出没有变化时官方视图无从开始；
③ 需要「AI 主写、人发起第一轮审阅」。因此保留笔记入口与审阅视图，但不重建状态体系。

## 2. 实体与存储

| 实体 | 存哪 | 说明 |
|:--|:--|:--|
| 笔记库根 | `notebook-config` | 单个记录；指向一个已注册的 DSH 工作区目录 |
| 笔记索引 | **派生** | 扫描根的 `.md/.markdown/.txt`；标题/类型/日期/标签由 frontmatter 解析 |
| 文件身份 | `note-file` | **惰性分配**（首次审阅时）；路径 + 内容哈希；改名后按哈希重新关联 |
| 草稿箱 | `note-draft` | 每个文件身份一条；存未提交批注 |
| 审阅历史 | `review-record` | 每次提交一条：会话 id + 文件快照元信息 + 批注；不存正文快照 |

审阅状态本身不落库：提交后的批注就是对话消息，另外按「独立审阅对象」留一份历史。

## 3. 入口页（笔记）

- 顶部：**新建** + 搜索 + 断开链接；
- 筛选：全部 / 未提交草稿 / 历史 / 缺元数据 / 空笔记；
- 列表：标题、路径、日期、标签、**缺元数据徽标**、草稿数徽标；
- 新建（自适应）：
  - 库根带 note2md 标记（`.note2md/` 或生成过的 AGENTS.md）→「用 note2md 新建」：
    开新会话并预填 note2md 指令（不注入、不自动发送）；
  - 普通目录 →「创建空笔记」（frontmatter + 标题）或「让 AI 起草」（新会话预填起草提示）；
- 历史视图：每条记录显示文件标题、路径、批注数、关联状态（已关联 / 已改名 / 原文已脱钩）、
  时间，可删除；顶部显示历史占用，**超过 2MB 用红色边框提示**（不弹窗）。

## 4. 审阅视图

- 入口：点笔记 → **在笔记库所属工作区新建会话**（官方 `startSession`）→ 右侧栏打开审阅 tab；
  不借用用户当前会话（避免污染无关上下文）；
- **默认源码视图**：每行行号 + 源文本；选中行区间后浮出小按钮「批注」，点击才弹意见框；
  批注锚定**精确行号区间 + 引用文本**，并在该区间下方就地显示批注卡片；高亮对应行；
- 顶部「整篇批注」：范围为整篇，引用用标题；
- 底部固定菜单：`批注 N` / `本轮改动 +A −D`（语义色胶囊）；点开为浮层，列出全部批注或 diff；
- 「本轮改动」= tab 打开时正文 vs 当前正文（官方 DiffBlock，默认收起）；可见时静默刷新；
- 「全部提交」：按编号插入新会话输入框（不自动发送），格式：

```
【批注 1】文件：Diary/x.md
行号：42-44
> 引用原文
意见：…
```

同时写入一条 `review-record` 历史并清空草稿箱。

## 5. 非目标

- 不做编辑器（0→1 在对话里完成）；不依赖 git、不桥接官方 diff；
- 不做轮次快照/历史 diff/接受状态/失效锚点/随包 skill；
- 不做笔记同步/备份/加密。

## 6. 验收标准

1. 未配置根时有引导；选目录后能列出 `.md/.txt`，缺元数据行有徽标；
2. 点笔记 → 在库工作区新开会话并打开审阅；无工作区时给出明确提示；
3. 源码视图行号精确；选中 → 小按钮 → 意见框；批注就地显示且高亮；
4. 草稿关 tab / 重启后仍在；全部提交后输入框出现编号批注（含精确行号），历史出现记录；
5. 改文件后「本轮改动」可见；历史可删除、占用超限红框提示；
6. `npm run verify` 与根 `check` 全绿。
