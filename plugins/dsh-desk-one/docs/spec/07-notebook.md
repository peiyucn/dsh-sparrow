# 07 · 批注：在工作区文件上写意见

> 状态（2026-11-15）：**已实现**（提交：改名 `9917055e`、host 工作区寻址 `1930fdd0`、右栏入口 `1955c9b1`、聚合接口 `a18f15a3`、落地页 `9b523c97`、旧页面与 host 清理 `66933536` / `15821dc9`）。首发版把「笔记库管理」和「批注」绑在一起；本次拆开：批注独立、按「工作区 + 文件」寻址，笔记库与索引/搜索/新建/技能全部删除，入口页改成「去批注」的落地页。
> 定位：AI 主写、人批注。批注对象是**工作区里的文件**（官方 Workspace files 能浏览到的 md / markdown / txt）；不做编辑器、不依赖 git、不桥接官方 diff。

## 1. 为什么改

原设计里「笔记库」是一个全局 root：面板的列表、索引、搜索都挂在它上面，右侧栏入口也要求文件在库根内。结果是：

- 新用户从官方文件浏览进来时没有批注入口（因为还没链接库），而这是最自然的首次接触路径；
- 库管理本身很弱——全部页列表 / 搜索 / 缺元数据 / 新建 / AI 起草，要么与官方文件浏览重复，要么低频；
- 真正有价值的是批注（逐行批注 → 进对话 → 本轮 diff）和「我有哪些草稿 / 记录」的管理。

所以：**批注与库解耦**。批注按「工作区 + 文件」寻址；库概念删除；入口页只保留「去批注」和三个聚合列表。

## 2. 实体与存储

| 实体 | 存哪 | 说明 |
|:--|:--|:--|
| 文件身份 | `note-file` | **惰性分配**（首次批注时）；工作区 + 相对路径 + 内容哈希；改名后按哈希重新关联 |
| 批注草稿箱 | `note-draft` | 每个文件身份一条；存尚未提交的批注 |
| 批注历史 | `review-record` | 每次提交一条：会话 id + 文件快照元信息 + 批注；不存正文快照 |
| 本轮基线 | `note-baseline` | 每个**批注会话**一条：该轮开始时正文；正文上限 1 MB，最多 200 条按更新时间淘汰；超限只留内存基线 |
| 批注会话标记 | `review-session` | 每个**批注会话**一条：文件身份 + 工作区 + 更新时间；最多 500 条淘汰，驱动侧栏图标与复用判定 |

**删除**：`notebook-config`（库根）与「笔记索引」（全部页 / 缺元数据都来自它）。

**批注本身不落库**：提交后的批注就是该批注会话的对话消息；`review-record` 只是按「独立批注对象」留一份历史（文件快照元信息 + 批注，不存被审正文）。落库的只有文件身份、草稿箱、提交记录、每会话基线与标记这五类。

**迁移**：已有的 `note-file` / `note-draft` / `note-baseline` / `review-record` / `review-session` 记录保持不变；`note-file` 新增 `workspaceId` 字段，旧记录缺该字段时按路径在已注册工作区里反查（查不到就按遗留记录处理，不删除）。`notebook-config` 不再读写，实现时删除对应路由与配置读取。

## 3. 入口页：批注落地页

目标：从面板进来，第一眼就是「去挑文件批注」，不需要先配置任何东西。

### 3.1 主操作区（页面中央，不是顶栏小按钮）

- **有工作区**：大字主按钮 **「打开工作区文件」**（英文对齐官方叫法 **Workspace files**），旁边一行说明「挑一个 Markdown / 文本文件，就能逐行批注、把批注发进对话」。
  点击 = 在**最近使用的工作区**新开会话并打开官方工作区文件页（`sidebarRight.openTab('files')`）；进入后由官方目录树挑文件。
- **没有工作区**：同一位置变成主按钮 **「新建工作区」**，点击走官方文件夹选择器 + 创建（与官方新建工作区同一套 `pickDirectory` + `workspaces.create`），建完直接接着打开工作区文件，一步到位。
- **工作区选择**：不要求用户预先指定；多工作区时默认最近使用的那个，进入会话后官方 workspace 下拉仍可切。页面上不出现「笔记库」字样。

### 3.2 三个聚合列表（有数据才显示）

- **批注草稿 N 处**：跨工作区聚合，行内带文件名 + 工作区名；点击回到该文件的批注视图（该文件的批注会话仍可复用时复用，见 4.1）。
- **批注记录 R 轮 / M 条**：**按文件折叠**——同一文件的多次提交只占一行，显示累计轮次与条数（标题与路径取最新一次提交）；点击回到该文件的批注视图，记录明细与删除仍在批注视图的「批注记录」浮层里。
- **最近批注**：按 `review-session` 标记的更新时间列出，点击回到批注视图。

列表沿用会话页的紧凑单行（32px 行高、13px 标题、11px 次级信息、发丝分隔）；数量小，先不做分页，卡片内滚动。

### 3.3 删除项

库链接 / 断开、全部页列表、分页、搜索、四档视图（全部 / 批注草稿 / 批注记录 / 缺元数据）、缺元数据视图、新建笔记、让 AI 起草、笔记技能选择——全部移除。

## 4. 批注视图与入口

- **官方预览入口**（推荐路径）：官方文件浏览与文档预览完全不动；**工作区内**的 md / markdown / txt 在官方预览头部多一个「批注视图」按钮（公开槽 `sidebar.right.tab.document.actions`）。
  点击 = 打开该文件的批注视图：该文件已有且仍可用的批注会话直接复用，否则在**文件所在工作区**新建会话，并在其中打开我们的批注 tab（默认源码视图）；官方预览本身不切模式、不注入 DOM，与官方行为互不影响；
- **面板入口**：入口页主按钮进入官方工作区文件页（会话页），之后同右栏路径；草稿 / 最近批注点一条 → 同上（先复用，没有才新建）；不借用用户当前会话；
- **4.1 批注会话复用**：批注会话在宿主 `desk_one` 域的 `review-session` 标记里记录文件的稳定 `fileId`、工作区与更新时间；点开同一篇时用该 `fileId` 取标记，按更新时间从新到旧挑第一个「会话仍在宿主会话列表、不在归档集、工作区一致」的会话，经官方 `uiWorkspace.openSession` 切过去，并等右侧栏 `mounted` 变成该会话后再打开批注 tab（避免把 tab 开到旧会话上）。
  同一篇有多个历史会话时优先挑有对话内容的（按官方 `refreshProjections` 读到的 `sessionStats.turns > 0` 判断）；旧行为留下的 0 轮空会话只在没有其它可用会话时才复用。
- **4.2 批注 tab 恢复**：官方右侧栏只持久化 tab 布局（id / kind / title），**不持久化 `navigation.params`**；批注 tab 自己按 `sessionId` 在浏览器存储记一份参数备忘（与官方布局同生命周期），缺失时依次用「宿主 `review-session` 标记（`fileId` + `workspaceId`）+ 批注记录的 `resolvedPath`」反推文件路径。因此直接点开旧批注会话也能恢复右侧批注视图，不再显示「没有指定文件」；恢复期间显示加载态。文件被改名导致记录脱钩、且没有参数备忘时仍会显示空态。
  找不到候选或全部失效时才新建会话。边界：文件改名会生成新的 `fileId`，按新文件处理（新建会话）；已删除 / 已归档的旧会话不会复用；`review-session` 标记上限 500 条按更新时间淘汰；会话列表尚未加载完时不做复用判断（宁可新建也不开错会话）。复用同一会话时本轮基线延续，不算新一轮；只有新建会话才按新基线开始新一轮。
- **视图切换**：「源码」（默认）/「渲染」；
  - 源码视图：每行行号 + 源文本；选中行后浮出小按钮「批注」（沿用面板按钮样式），点击才弹输入框；输入框**就地渲染在选中行下方**并自动聚焦；保存的批注锚定**精确行号区间 + 引用文本**，高亮对应行并在行下就地显示卡片；
  - 取消联动：Esc、点输入框外、点「取消」都会关闭输入框并同时清掉选中高亮与浏览器原生选区；**只显示「批注」浮钮、尚未输入时**，点页面其它任何位置也会取消选中，不会留下无法退出的高亮；
  - 输入框**必须留在选中行下方**（静态文档流），不得绝对定位到面板底部；评审按此验收；
  - 输入框与已保存批注**同槽位同视觉**：相同的左缩进（对齐行号右侧）、相同的品牌色左竖线，先输入、保存后原位变成批注卡片；
  - 渲染视图：只读阅读；批注请在源码视图操作；
- 顶部「整篇批注」：范围为整篇，引用用标题；
- 顶部工具条：**模仿官方文档预览的表头**——38px 行高、发丝底边；视图切换用官方「当前查看器」按钮 + 下拉菜单（只有 `Markdown` / `代码` 两项，代码 = 源码 + 批注，默认；不提供纯文本）；复制路径 / 刷新用官方 Button ghost + Tooltip，整篇批注用官方 outline Button；
- 底部固定菜单：两枚 **split 按钮**（官方任务页「新建」按钮的主按钮 + 第二段图标形状）——
  `提交批注`＋清单笔图标（直接打开 `批注草稿 N 处`，主按钮直接提交）、`本轮改动 +A −D`＋时钟图标（主按钮开改动浮层，图标直接打开 `批注记录 R 轮 / M 条`）；按钮 36px 高、离底边 18px；整组直接用官方主按钮 token（深色主题近白底 + 深色字，浅色主题官方品牌深底 + 白字；无整条底衬、不依赖 theme-tone）；滚动内容延伸到按钮下方，底部用 `::after` 渐隐到 `bg-base`（同官方 @ / 列表底部）；滚动区末尾留出按钮净空（36px 按钮高 + 18px 底距 + 14px 余量，`--dsh-desk-review-bar-clear`），滚到底时最后一行停在按钮上方、可继续选中批注；第二段图标直接打开对应浮层，不再套一层菜单；面板宽度不足时主标签以省略号截断、箭头保持可点（容器查询 ≤430px 收紧）；批注记录浮层显示轮次 / 条数，按当前 fileId（或解析后的路径）列出已提交记录，含时间、批注条数、引用与意见；
  批注 / 改动浮层仍用官方菜单面（menu surface token + 圆角 + elevation），其底边与按钮顶留 4px 间距；点击浮层外或按 Esc 关闭；提交 / 收起用官方 Button；
- frontmatter：代码视图把 `page.frontmatter` 原始块（含两条 `---` 围栏）作为源码行显示，行号与真实文件一致；MD 视图在正文前把 `page.fields` 内联渲染为只读元数据块，随内容一起滚动，**不吸顶**（与官方 markdown / 代码展示一致）。
- 本轮基线：**按批注会话（sessionId）** 持久化在宿主 `desk_one` 域的 `note-baseline` 记录（不是浏览器 storage，清浏览器缓存不丢；正文上限 1MB（与可批注文件上限一致），超限删除宿主记录、只保留内存基线；最多保留 200 条按 `updatedAt` 淘汰）。打开批注时若无该会话的基线，自动取当前正文作为本轮基线；刷新 / 重开同一个 tab 不重置；新开一个批注会话即自动开始新一轮，不再提供「以当前为基线」按钮。
- 侧栏标记：批注会话在官方 `sidebar.session.row.leading`（root 级，16px 前置格）注册 **Desk One 徽标字形（「✦」）**标记，图标本身染官方业务蓝（`--dsw-alias-state-business-primary`，不加底色 / 圆底）；批注 tab 标题仍用笔记功能区 tab 图标（面板内保持单色，与相邻 tab 标题一致）；标记由宿主 `desk_one` 域的 `review-session` 节点持久化（每会话一条，上限 500 条按 `updatedAt` 淘汰），客户端启动时 hydrate；行处于运行 / 待处理状态时官方用状态点替换该格，此时同一标记改注册到 `sidebar.session.row.trailing`（时间标签后）继续显示；归档行不显示。
- 对话提示：批注会话在官方 `conversation.input.overlay`（session 级）注册一个输入框内的 placeholder 式引导「在右栏选中文字、点「批注」；提交会把批注填进输入框，发送后才开始修订。」；该引导**只在批注视图 tab 处于在屏（`visible`）状态时显示**——批注会话仍可能在右侧栏开着官方工作区文件页，此时用户还没点预览头部的「批注视图」进入批注模式，提前显示批注引导会误导；批注视图回到屏上时再出现。空白新会话与对话已开始的会话一致：输入框为空时该引导顶替官方 placeholder；开始输入后官方 placeholder 消失，引导随之隐藏，清空后重新出现。引导的字体与盒模型逐项对齐官方 placeholder（同一行高与字号，文字起点与光标同一条线：距卡片顶 12px、左 14px、右 12px，因为 overlay 锚点在卡片 border box 顶而官方 placeholder 在卡片 8px 顶距 + 输入区 4px 内距之下）；停靠态单行省略号，空白会话（`data-phase="hero"`）按官方规则两行截断。
- 视觉规范：入口页、批注 tab、官方预览按钮统一用官方主题 token 与官方基础组件（Button / Input / SegmentedTabs / Pill / Tag / Modal），不自造按钮/胶囊样式；官方预览头部的「批注视图」按钮与相邻头部按钮一致（官方 ghost 图标按钮，无彩色底、同一间距），仅图标本身（「✦」同桌标记）与侧栏批注标记同用官方业务蓝；16px 头部尺寸下该字形描边按 2.0 输出（24 网格的 1.6 缩到 16px 只剩约 1.07px，会被抗锯齿吃掉），并用官方 `Tooltip`、**不叠加原生 `title`**（否则会出两个提示）。底部按钮使用官方主按钮材质，不复制自定义玻璃组件。
- 「本轮改动」= tab 打开时正文 vs 当前正文（官方 DiffBlock，默认收起）；可见时静默刷新；代码视图把本轮新增 / 改写的行用官方 diff-added 底色 + 左侧绿色竖线就地高亮，与底部「本轮改动 +A −D」共用同一份行级 diff（同样的行切分与 256 编辑上限整段回退），批注 / 选中行的高亮叠加在其上；
- 「提交批注」：按编号插入新会话输入框（不自动发送），格式：

```
【批注 1】文件：Diary/x.md
行号：42-44
> 引用原文
意见：…
```

同时写入一条 `review-record` 批注记录并清空批注草稿箱。

## 5. 与官方文件浏览的边界

- **不动**官方工作区文件页与文档预览：不注册地址接管、不替换渲染器、不注入 DOM；
- 复用公开槽给官方预览头部加一个按钮；文件导航继续用官方目录树（预览头部的目录树按钮）；
- **不注册官方 document renderer**：注册后会对所有 md 生效、且批注要绑定当前会话，代价大于收益；只**模仿**官方预览的表头样式，视图切换用官方「当前查看器」按钮 + 下拉菜单（`Markdown` / `代码` 两项，默认代码）；
- 入口页**不自建目录树**：整棵树只在官方工作区文件页里浏览；入口页只做「去批注」与三个聚合列表。

## 6. 非目标

- 不做笔记库 / 索引 / 搜索 / 缺元数据 / 新建笔记 / AI 起草（本次删除）；
- 不做编辑器（0→1 在对话里完成）；不依赖 git、不桥接官方 diff；
- 不做轮次快照 / 历史 diff / 接受状态 / 失效锚点；不随包笔记专用 skill（插件随包的是 `desk-one` 操作指南 skill，不是笔记写作技能）；
- 不做笔记同步/备份/加密；渲染视图不承载批注交互。

## 7. 验收标准

1. 没有工作区时，入口页中央只有「新建工作区」+ 说明；点击走官方文件夹选择器，建完直接打开官方工作区文件页。
2. 有工作区时，入口页中央是「打开工作区文件」；点击在最近使用的工作区新开会话并打开官方工作区文件页；进入后官方 workspace 下拉可切。
3. 入口页不出现：库链接 / 断开、全部页列表、分页、搜索、四档视图、缺元数据、新建笔记、AI 起草、技能选择。
4. 批注草稿 / 批注记录 / 最近批注：有数据才显示；三条都可回到批注视图；同一文件的记录折叠为一行（R 轮 / M 条），同一文件的最近批注只保留最新一条，记录明细与删除在批注视图的记录浮层里。
5. 官方预览头部对**任一工作区内的**可批注后缀文件出现「✦」按钮，点击复用或新建批注会话并显示源码视图；非工作区文件不出现该按钮；官方预览行为不变。
6. 批注视图行为不变：行号精确；选中 → 小按钮 → 行下输入框（自动聚焦）；批注高亮 + 就地展示；可切「渲染」只读视图；**仅显示「批注」浮钮时点其它位置也会取消选中**；对话提示只在批注视图在屏时出现。
7. 删除库后旧的 `notebook-config` 记录与索引路由不再被读写；已有草稿 / 记录 / 基线不丢；`note-file` 缺 `workspaceId` 的旧记录按路径反查工作区。
8. 「提交批注」后输入框出现编号批注（含精确行号），批注记录出现对应条目；顶部工具条、图标动作、底部两枚 split 按钮、浮层都用官方组件与主题 token。
9. `npm run verify` 与根 `check` 全绿。
