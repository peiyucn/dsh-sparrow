# 07 · 笔记（最小版）：AI 主写 + 人批注

> 状态（2026-11-15）：**已实现并恢复**（首发版本 0.2.2-rc.3；模块已按 `client/notebook/review/` 拆分重构）。2026-11-15 的回退与调整：恢复「链接工作区 + 文件列表 / 搜索 / 四档视图」的笔记页，**删除新建笔记（含 AI 起草 / 技能选择）**；tab 名改为「**笔记批注 / Annotations**」；工作区选择在**面板顶栏**（已注册工作区 + 新建工作区，不提供选择文件夹 / 取消链接），首页默认直接展示工作区列表；页面顶部一行左侧是搜索框、右侧是白色「工作区文件」按钮，四档视图与「共 N 篇」、翻页收进列表表头。右栏批注入口保持对所有工作区文件开放。
>
> 定位：维护笔记库与批注视图的入口；**AI 主写、人批注**；不做编辑器、不依赖 git、不与官方 diff 审阅桥接。

## 1. 为什么是这个形态

官方「变更请求 → 本地变更」只在 **git 检出 + 有变更** 时可用，定位是「有改动后的评论」；
笔记场景多为：① 目录由网盘同步、没有 git；② 文档相对检出没有变化时官方视图无从开始；
③ 需要「AI 主写、人发起第一轮审阅」。因此保留笔记入口与审阅视图，但不重建状态体系。

## 2. 实体与存储

| 实体 | 存哪 | 说明 |
|:--|:--|:--|
| 笔记库根 | `notebook-config` | 单个记录；指向一个已注册的 DSH 工作区目录（或其子目录）；就是面板顶栏工作区选择器显示的库根 |
| 笔记索引 | **派生** | 扫描根的 `.md/.markdown/.txt`；标题/类型/日期/标签由 frontmatter 解析 |
| 文件身份 | `note-file` | **惰性分配**（首次审阅时）；路径 + 内容哈希；改名后按哈希重新关联 |
| 批注草稿箱 | `note-draft` | 每个文件身份一条；存尚未提交的批注 |
| 审阅历史 | `review-record` | 每次提交一条：会话 id + 文件快照元信息 + 批注；不存正文快照 |
| 本轮基线 | `note-baseline` | 每个**审阅会话**一条：该轮开始时正文；正文上限 1 MB，最多 200 条按更新时间淘汰；超限只留内存基线 |
| 审阅会话标记 | `review-session` | 每个**审阅会话**一条：文件身份 + 工作区 + 更新时间；最多 500 条淘汰，驱动侧栏图标与复用判定 |

**批注本身不落库**：提交后的批注就是该审阅会话的对话消息；`review-record` 只是按「独立审阅对象」留一份历史（文件快照元信息 + 批注，不存被审正文）。落库的只有根配置、文件身份、草稿箱、提交记录、每会话基线与标记这六类。

## 3. 入口页（管理面，不是浏览器）

浏览与阅读交给官方右侧栏文件浏览。**DSH 的右侧栏只在会话页存在**（面板页没有会话 surface，
`sidebarRight.openTab` 会拒绝），所以「中间留 Desk One、右边开官方文件树」在现版 DSH 做不到；
入口页提供两条进入审阅的路：① 搜索 / 最近列表里点某一篇 → 进入该笔记的审阅会话（已有的审阅会话仍可用时直接复用，见 4.1；没有才新开）；
② 显式点「浏览工作区文件」→ 新开会话并打开官方文件页（此时切到会话页，之后在官方树里自选文件）。
进入审阅会话后，该会话的官方右侧栏文件树即成为浏览入口。官方目录树与官方预览我们不复制、不改动。
入口页本身只做（页面固定一屏高，列表在卡片内滚动）：

- **面板顶栏**：工作区选择器（未链接显示「选择工作区」，链接后显示「工作区 <标题>」）＋「新建工作区…」；不提供选择文件夹 / 取消链接；
- **顶部一行**：左侧官方搜索框（占满剩余宽度）；右侧固定 **340px** 宽的白色主按钮（文案见 3.1）；两者合计宽度与下方列表卡片一致，中英文下宽度不变；
- **列表工具栏（卡片表头）**：四档视图（官方 `SegmentedTabs`，按内容宽度，不铺满整行）在左；右侧依次是「共 N 篇」、「第 x / y 页」与上一页 / 下一页；「缺元数据」视图在计数旁显示 frontmatter 解释；
- **列表**：与会话页同款紧凑单行行高（32px、13px 标题、11px 次级信息、l1 发丝分隔），
  标题列固定宽度、路径列对齐；默认每页 **20 条**；
- **批注记录**：点一条记录打开只读详情（官方 `Modal`）：文件、时间、批注列表；
  原文找不到时只提示「原文可能改路径了」，不展示「关联 / 改名 / 脱钩」这类概念；可删除记录、
  能解析原文时可直接打开原文；
- **未链接（首页）**：**默认直接展示已注册工作区列表**（不折叠、不需先点按钮），点一行即链接；列表下方是「新建工作区…」与两行灰色说明（中英文各自维护）。

### 3.1 工作区选择与「工作区文件」

- 工作区在**面板顶栏**选择：未链接时按钮显示「选择工作区」，链接后显示「工作区 <标题>」；点开菜单只列已注册工作区与「新建工作区…」，**不提供选择文件夹 / 取消链接**；点一项直接改写 `notebook-config.rootPath`，**不需要先断开**；切换后搜索与视图复位到「全部」第一页。
- 顶部一行：左侧搜索框（占满剩余宽度），右侧白色主按钮「**浏览工作区文件，点击 ✦（Desk One 标）开始批注**」（英文 `Browse workspace files, click ✦ to annotate`）固定 **340px** 宽、32px 高，文字单行；两者合计宽度与列表一致，中英文下宽度不变。点击打开当前工作区（未链接时取第一个已注册工作区；一个都没有时先走新建工作区）的官方文件页。
- 工作区列表与顶栏选择器使用同一份已注册工作区数据；两处都不出现「选择文件夹」「取消工作区」。

### 3.2 官方预览头部的「批注」入口

- 官方文件浏览与文档预览**一行不改**；通过公开槽 `sidebar.right.tab.document.actions`
  在官方预览头部为**任一工作区内的** md/markdown/txt 增加一个**「✦」同桌标记的官方 ghost 图标按钮**（与相邻头部按钮同规格、同间距、不加彩色底；图标本身用官方业务蓝 `--dsw-alias-state-business-primary`，与侧栏批注标记同色）；
- 点击 = 打开该文件的批注视图（该文件已有且仍可用的批注会话直接复用，否则在**文件所在工作区**新建）并打开批注 tab（默认源码视图）；官方预览不切模式、不注入 DOM；
- **不要求文件在链接的笔记库内**：右栏入口对所有工作区文件开放（owner 2026-11-15 决策）；链接的笔记库只决定面板页列出哪个目录。

## 4. 审阅视图与入口

入口见 3.2；以下记录审阅视图内部行为。

- **4.0 入口与默认会话**：官方预览头部的「批注」主入口默认在**当前会话**打开审阅 tab，不新建、不切会话；旁边的「＋」次入口「在新会话审阅」显式新建专用批注会话。笔记页入口没有当前会话，保持「复用已有审阅会话，否则新建」的既有路径。
- **4.1 审阅会话复用**：审阅会话在宿主 `desk_one` 域的 `review-session` 标记里记录笔记的稳定
  `fileId`、工作区与更新时间；点开同一篇时用该 `fileId` 取标记，按更新时间从新到旧挑第一个
  「会话仍在宿主会话列表、不在归档集、工作区一致」的会话，经官方 `uiWorkspace.openSession`
  切过去，并等右侧栏 `mounted` 变成该会话后再打开审阅 tab（避免把 tab 开到旧会话上）。
  同一篇有多个历史会话时优先挑有对话内容的（按官方 `refreshProjections` 读到的
  `sessionStats.turns > 0` 判断）；旧行为留下的 0 轮空会话只在没有其它可用会话时才复用。
- **4.2 审阅 tab 恢复**：官方右侧栏只持久化 tab 布局（id / kind / title），**不持久化
  `navigation.params`**；审阅 tab 自己按 `sessionId` 在浏览器存储记一份参数备忘（与官方布局同
  生命周期），缺失时依次用「宿主 `review-session` 标记（`fileId` + `workspaceId`）+ 批注记录的
  `resolvedPath`」反推笔记路径。因此直接点开旧审阅会话也能恢复右侧审阅视图，不再显示「没有指定
  文件」；恢复期间显示加载态。文件被改名导致记录脱钩、且没有参数备忘时仍会显示空态。
  找不到候选或全部失效时才新建会话。边界：文件改名、库重新链接都会生成新的 `fileId`，按新笔记
  处理（新建会话）；已删除 / 已归档的旧会话不会复用；`review-session` 标记上限 500 条按更新时间淘汰；
  会话列表尚未加载完时不做复用判断（宁可新建也不开错会话）。复用同一会话时本轮基线延续，
  不算新一轮；只有新建会话才按新基线开始新一轮。
- **4.3 标记与清除**：打开审阅 tab 本身不写 `review-session` 标记、不显示会话行图标；当前会话在**首次保存批注**（或提交批注）时才标记；显式「在新会话审阅」和笔记页新建专用会话时，在审阅 tab 打开后立即标记。误标记可点会话行「✦」徽标清除（DELETE `/notebook/review-sessions`），清除只删标记，不删会话或批注。
- **视图切换**：「源码」（默认）/「渲染」；
  - 源码视图：每行行号 + 源文本；选中行后浮出小按钮「批注」（沿用面板按钮样式），点击才弹
    输入框；输入框**就地渲染在选中行下方**并自动聚焦；保存的批注锚定**精确行号区间 + 引用文本**，
    高亮对应行并在行下就地显示卡片；
  - 取消联动：Esc、点输入框外、点「取消」都会关闭输入框并同时清掉选中高亮与浏览器原生选区；
    **只显示「批注」浮钮、尚未输入时**，点页面其它任何位置也会取消选中，不会留下无法退出的高亮；
  - 输入框**必须留在选中行下方**（静态文档流），不得绝对定位到面板底部；评审按此验收；
  - 输入框与已保存批注**同槽位同视觉**：相同的左缩进（对齐行号右侧）、相同的品牌色左竖线，
    先输入、保存后原位变成批注卡片；
  - 渲染视图：只读阅读；批注请在源码视图操作；
- 顶部「整篇批注」：范围为整篇，引用用标题；
- 顶部工具条：**模仿官方文档预览的表头**——38px 行高、发丝底边；视图切换用官方「当前查看器」按钮 + 下拉菜单（只有 `Markdown` / `代码` 两项，代码 = 源码 + 批注，默认；不提供纯文本）；复制路径 / 刷新用官方 Button ghost + Tooltip，整篇批注用官方 outline Button；
- 底部固定菜单：两枚 **split 按钮**（官方任务页「新建」按钮的主按钮 + 第二段图标形状）——
  `提交批注`＋清单笔图标（直接打开 `批注草稿 N 处`，主按钮直接提交）、`本轮改动 +A −D`＋时钟图标（主按钮开改动浮层，图标直接打开 `批注记录 R 轮 / M 条`）；按钮 36px 高、离底边 18px；整组直接用官方主按钮 token（深色主题近白底 + 深色字，浅色主题官方品牌深底 + 白字；无整条底衬、不依赖 theme-tone）；滚动内容延伸到按钮下方，底部用 `::after` 渐隐到 `bg-base`（同官方 @ / 列表底部）；滚动区末尾留出按钮净空（36px 按钮高 + 18px 底距 + 14px 余量，`--dsh-desk-review-bar-clear`），滚到底时最后一行停在按钮上方、可继续选中批注；第二段图标直接打开对应浮层，不再套一层菜单；面板宽度不足时主标签以省略号截断、箭头保持可点（容器查询 ≤430px 收紧）；批注记录浮层显示轮次 / 条数，按当前 fileId（或解析后的路径）列出已提交记录，含时间、批注条数、引用与意见；
  批注 / 改动浮层仍用官方菜单面（menu surface token + 圆角 + elevation），其底边与按钮顶留 4px 间距；点击浮层外或按 Esc 关闭；提交 / 收起用官方 Button；
- frontmatter：代码视图把 `page.frontmatter` 原始块（含两条 `---` 围栏）作为源码行显示，行号与真实文件一致；MD 视图在正文前把 `page.fields` 内联渲染为只读元数据块，随内容一起滚动，**不吸顶**（与官方 markdown / 代码展示一致）。
- 本轮基线：**按审阅会话（sessionId）** 持久化在宿主 `desk_one` 域的 `note-baseline` 记录（不是浏览器 storage，清浏览器缓存不丢；正文上限 1MB（与可审阅文件上限一致），超限删除宿主记录、只保留内存基线；最多保留 200 条按 `updatedAt` 淘汰）。打开审阅时若无该会话的基线，自动取当前正文作为本轮基线；刷新 / 重开同一个 tab 不重置；新开一个审阅会话即自动开始新一轮，不再提供「以当前为基线」按钮。
- 侧栏标记：审阅会话在官方 `sidebar.session.row.leading`（root 级，16px 前置格）注册 **Desk One 徽标字形（「✦」）**标记，图标本身染官方业务蓝（`--dsw-alias-state-business-primary`，不加底色 / 圆底）；审阅 tab 标题仍用笔记功能区 tab 图标（面板内保持单色，与相邻 tab 标题一致）；标记由宿主 `desk_one` 域的 `review-session` 节点持久化（每会话一条，上限 500 条按 `updatedAt` 淘汰），客户端启动时 hydrate；**标记只在首次批注 / 新建专用会话后写入**，当前会话仅打开审阅 tab 不写；点会话行徽标可清除误标记（只删标记，不删会话或批注）；行处于运行 / 待处理状态时官方用状态点替换该格，此时同一标记改注册到 `sidebar.session.row.trailing`（时间标签后）继续显示；归档行不显示。
- 对话提示：审阅会话在官方 `conversation.input.overlay`（session 级）注册一个输入框内的 placeholder 式引导「在右栏选中文字、点「批注」；提交会把批注填进输入框，发送后才开始修订。」；该引导**只在审阅视图 tab 处于在屏（`visible`）状态时显示**——审阅会话仍可能在右侧栏开着官方文件浏览（从笔记页「浏览文件」进入），此时用户还没点预览头部的「审阅视图」进入审阅模式，提前显示批注引导会误导；审阅视图回到屏上时再出现。空白新会话与对话已开始的会话一致：输入框为空时该引导顶替官方 placeholder；开始输入后官方 placeholder 消失，引导随之隐藏，清空后重新出现。引导的字体与盒模型逐项对齐官方 placeholder（同一行高与字号，文字起点与光标同一条线：距卡片顶 12px、左 14px、右 12px，因为 overlay 锚点在卡片 border box 顶而官方 placeholder 在卡片 8px 顶距 + 输入区 4px 内距之下）；停靠态单行省略号，空白会话（`data-phase="hero"`）按官方规则两行截断。
- 视觉规范：入口页、审阅 tab、官方预览按钮统一用官方主题 token 与官方基础组件
  （Button / Input / SegmentedTabs / Pill / Tag / Modal），不自造按钮/胶囊样式；
  官方预览头部的「审阅视图」按钮与相邻头部按钮一致（官方 ghost 图标按钮，无彩色底、同一间距），仅图标本身（「✦」同桌标记）与侧栏审阅标记同用官方业务蓝；16px 头部尺寸下该字形描边按 2.0 输出（24 网格的 1.6 缩到 16px 只剩约 1.07px，会被抗锯齿吃掉）。底部按钮使用官方主按钮材质，不复制自定义玻璃组件。
- 「本轮改动」= tab 打开时正文 vs 当前正文（官方 DiffBlock，默认收起）；可见时每 5 秒静默刷新，从隐藏回到可见（或窗口重新获得焦点）时立即刷新，不要求用户手动刷新页面；代码视图把本轮新增 / 改写的行用官方 diff-added 底色 + 左侧绿色竖线就地高亮，与底部「本轮改动 +A −D」共用同一份行级 diff（同样的行切分与 256 编辑上限整段回退），批注 / 选中行的高亮叠加在其上；
- 「提交批注」：按编号插入新会话输入框（不自动发送），格式：

```
【批注 1】文件：Diary/x.md
行号：42-44
> 引用原文
意见：…
```

同时写入一条 `review-record` 批注记录并清空批注草稿箱。

## 5. 官方文件浏览的复用边界

- **不动**官方文件页与文档预览：不注册地址接管、不替换渲染器、不注入 DOM；
- 复用公开槽给官方预览头部加一个按钮；文件导航继续用官方目录树（预览头部的目录树按钮）；
- **不注册官方 document renderer**：注册后会对所有 md 生效、且批注要绑定当前会话，代价大于收益；
  只**模仿**官方预览的表头样式，视图切换用官方「当前查看器」按钮 + 下拉菜单（`Markdown` / `代码` 两项，默认代码）；
- 入口页**不自建目录树**：整棵树只在官方文件页里浏览；入口页列表只是分页的全部 / 记录视图；

## 6. 非目标

- 不做编辑器（0→1 在对话里完成）；不依赖 git、不桥接官方 diff；
- 不做轮次快照 / 历史 diff / 接受状态 / 失效锚点；不随包笔记专用 skill（只随包 `desk-one` 操作指南 skill）；
- 不做笔记同步/备份/加密；渲染视图不承载批注交互。

## 7. 验收标准

1. 未链接时：面板顶栏按钮为「选择工作区」；首页默认直接列出已注册工作区（一个都没有时显示新建提示），
   点一行即链接；下方是「新建工作区…」与中英文说明，不提供选择文件夹 / 取消链接；
2. 链接后：顶栏显示「工作区 <标题>」，同一菜单可切换已注册工作区或新建；**不需要先断开**；
   顶部一行左侧是搜索框，右侧是固定 340px 宽、32px 高、文字单行的白色「浏览工作区文件，点击 ✦（Desk One 标）开始批注」
   按钮，两者合计宽度与列表一致，中英文下不变；列表卡片的表头是四档视图 + 「共 N 篇」+ 翻页；
3. 笔记页固定一屏高，不出现整页滚动条；列表与会话页同款紧凑行，每页 20 条；
   四档视图（全部 / 批注草稿 / 批注记录 / 缺元数据）可切换，缺元数据行有徽标，该视图顶部解释
   frontmatter 是什么；
4. 批注记录行可点击打开只读详情（文件、时间、批注列表）；原文找不到时只提示「原文可能改路径了」，
   界面不出现「关联 / 改名 / 脱钩」这类概念；能解析原文时可直接「打开原文」或删除记录；
5. 任一工作区内的 md 在官方预览头部出现与相邻按钮同款的 ghost「批注」按钮，点击后打开该文件的
   批注视图（已有且可用的批注会话复用，否则在文件所在工作区新建）并显示源码视图；**不要求文件在
   链接的笔记库内**；官方预览行为不变；
6. 官方预览的「批注」主入口默认在当前会话打开审阅 tab，不新建会话、不切换会话；「＋ / 在新会话审阅」才显式新建；笔记页入口仍复用该笔记已有且仍可用的审阅会话，没有时才在库工作区新开会话；无工作区时给出明确提示；
6.1 打开审阅 tab 本身不写标记、不显示会话行图标；首次保存批注（或提交）后才标记；显式新会话在打开后立即标记；点会话行徽标可清除误标记；
7. 源码视图行号精确；选中 → 小按钮 → 行下输入框（自动聚焦）；批注高亮+就地展示；可切「渲染」
   只读视图；**仅显示「批注」浮钮时点其它位置也会取消选中**；
8. 审阅页术语与入口页一致：批注草稿 / 批注记录 / 批注；「提交批注」后输入框出现编号批注
   （含精确行号），批注记录出现对应条目；顶部工具条、图标动作、底部两枚 split 按钮、浮层都用官方组件与
   主题 token（两枚 split 按钮居中、浮层是官方菜单面）；
9. 会话页列表与笔记页同款：32px 单行行高、13px 标题、11px 次级信息、同规格徽标与动作按钮；
10. 改文件后「本轮改动」可见；批注记录可删除、占用超限时显示红色占用提示；
11. `npm run verify` 与根 `check` 全绿。

## 命名约定（补充）

* 功能与视图叫「**笔记批注 / Annotations**」：笔记批注（右栏 tab）、官方预览头部的「批注」入口、批注视图。
* 页面与库仍叫「**笔记页 / 笔记库**」：链接工作区、文件列表、搜索、四档视图；库根是 `notebook-config`。
* 单条意见与它的产物叫「**批注**」：批注、批注草稿、批注记录、提交批注、N 批注。
