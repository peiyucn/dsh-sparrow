# dsh-desk-one

[English](README.md) | 简体中文

**同桌**（Desk One）—— DSH Web 里与 harness 共用的办公桌：一个左侧栏入口、一块面板、一套统一对象模型，每个标签都建在同一套数据上。便签、任务板、日程与 agent 会话收在同一处，日程可聚合企业微信 / iCloud / Outlook 个人日历（只读）。

## 它是什么

* 左侧栏只有一个入口 **同桌**（Desk One）；功能收在面板内的标签页里，不散落到界面各处。面板外观参考官方对话区页头，功能内操作按钮沿用官方插件页的按钮形状。
* **日程** 放在最前面：聚合企业微信 / iCloud / Outlook 个人与公开 ICS 订阅的只读日历。
* **便签墙** 是第一个落地功能：一面自由摆放的便签墙，而不是一张录入表单。
* **任务板** 是固定三泳道看板（待办 / 进行中 / 完成），支持颜色标签、按天截止日期、拖拽推进、分组与存档。
* **日程** 把企业微信 / iCloud CalDAV、Outlook 个人（Graph OAuth）与任意公开 ICS 订阅聚合成一个只读页面：上排是「今日」与「近期」，下方是月历 / 周历 / 日历（月历默认、周一起始、5–6 行自适应；周历一屏 8 小时、默认锚定当前时间可滚动），点事件在点击位置附近弹卡片，完整连接与日历管理在顶栏「日历源」进入的管理页；日历源、便签垃圾桶、任务存档三个子页共用标题 + 统计排版，返回按钮统一在顶栏右侧。
* **会话** 是共享的 agent 会话目录：活跃会话按工作区分组；归档区可取消归档、移入回收站；游离会话与回收站（还原 / 彻底删除）也在同一页管理，破坏性操作要逐字输入会话标题确认。面板顶栏对齐官方对话区：76px 高的顶栏（默认官方黑白实色，启用 theme-tone 时才变玻璃），第一行是品牌标题 + 一行小字说明和当前功能动作，第二行是官方同款纯文字标签（当前项 2px 下划线），末尾留有官方同款省略号 More 按钮（只放溢出页面；当前没有溢出项，打开是贴着按钮、宽度随内容收缩的模糊菜单，显示「更多功能开发中…」）；以后新页面可以移进去，标签条不会无限变长。顶栏是固定 76px 浮层，各功能内容首屏都从其下方开始，滚动时内容从玻璃下经过；便签墙全宽铺满，末尾省略号打开浮动模糊页面菜单。

## 环境要求

* 要求 DSH 0.2.2-rc.1，与本仓库其它插件钉的版本线一致。
* Node.js 24 或更高，与 DSH 宿主要求一致。
* 便签 / 任务板 / 会话管理不需要联网或账号配置；**日程页的日程聚合**需要你在面板里自行连接至少一个来源（企业微信 CalDAV 同步密码、iCloud App 专用密码，或 Outlook 个人账号发布的 ICS 链接），并由本机访问对应服务。

## 安装

* `dsh plugin --profile web add @dsh-sparrow/dsh-desk-one`
* 安装后重启 dsh web；只刷新浏览器不够，客户端 bundle 由宿主启动时读入。
* 然后在鲸鱼侧栏里点 **同桌**。

## 使用

* **笔记** 目前是空白占位（内容按独立规划推进）；打开同桌默认落在日程页，不让人先看到空页面。
* 点标题行右侧的 **随手记**，或双击墙面空白处：贴纸会落在该位置、显示在最上层并自动获得输入焦点；同一组标题行动作里还放着 **Smash!** 和垃圾桶入口；空墙中央有很淡的两行提示。
* 墙面是**固定宽度、纵向无限**的画布：把贴纸拖到屏幕底部会自动向上滚动，贴纸可以落在当前屏幕下方，墙面纵向滚动到它。
* 直接在贴纸上写；失焦即保存，内容被清空的贴纸会直接移除，不在墙上留空贴纸。
* 按住贴纸正文拖动就能摆放；左上角有一枚紧凑的六点抓握纹，提示这里可以抓。点过或拖过哪张，哪张就显示在最上层，这个层级也会保存下来。
* 拖贴纸右下角可以改大小；位置与尺寸都会按便签各自保存。
* 鼠标悬停贴纸会显示颜色圆点与一组小图标操作；离开同桌再回来，会停在上次所在的标签页。
* 贴纸上的**小垃圾桶图标**把它丢进垃圾桶但不删除（和 Smash 同一段飞散动画）；垃圾桶按钮用一条细分隔线与墙面操作隔开，点它是进入垃圾桶视图，行内图标可以恢复或永久删除。墙上最多 **100** 张便签、垃圾桶最多 **200** 张；垃圾桶顶部显示总数，一次渲染 10 行，点「加载更多」继续加载。垃圾桶按钮不挂角标——只有真正未读的东西才值得抢注意力。
* **Smash!** 是顶栏里的危险色动作按钮：二次确认后把墙上所有便签一把扔进垃圾桶，带一段飞散动画；它常驻显示，墙上没有便签时点了没反应，点击其它地方或按 **Esc** 会取消确认；垃圾桶装不下时会被拦下并提示先清空。
* 打开 **任务板** 是固定三泳道看板：点列头 **＋**，或双击泳道空白处新建卡片；卡片显示自动换行的标题与描述、一个叠放色卡（当前颜色在最上、其它颜色从后面露出来；点开五色板直接选）、一个按天截止日期的日历按钮（未设置时只有图标，设置后显示图标 + 日期，再点可修改）。单击标题或描述进入编辑；平时文字是普通文本，所以**整张卡片都是拖拽区**。只剩一天截止的卡片会带琥珀色描边，逾期显示红字；只有 **完成** 列的卡片与分组能存档。
* 按住卡片任意位置就能拖：一张副本跟着鼠标走，泳道会高亮；掉在无效位置时卡片会飞回原处。拖进泳道改状态、拖到卡片上改顺序；拖动时目标泳道和分组会高亮，并用一条蓝色插入线标出松手后的准确位置。删除需要再点一次确认。
* 标题行动作可切换 **手动排序 / 创建时间 / 截止日期**，**完成** 列可折叠。**＋ 分组** 在泳道里建一层真正的分组（可以一直为空）：卡片能拖进拖出、双击名字就地改名、拖六点手柄调整顺序。分组头用两行（名称一行、任务计数一行），长名字和操作图标在窄泳道里也放得下。未分组卡片与分组块共享**同一条手动序列**，分组可以拖到卡片之间（卡片也可以落到两个分组之间）。整组拖动和拖卡片完全一样：按住分组头拖动时整块（头 + 卡片）跟着鼠标走，拖到别的泳道直接连同卡片一起移动（移回来也一样便宜），同泳道内放下则调整分组顺序；删除分组只解散分组、卡片回到未分组。**完成** 列的分组头还会多一个存档按钮：整组连同卡片离开板面，存档视图里以一条分组条目展示；恢复会把整组和卡片一起拉回，删除存档分组则连同卡片一起彻底删除。**存档** 里可以恢复或永久删除存档任务。
* 打开 **会话** 查看共享的 agent 会话目录：活跃、归档、游离、回收站四个分区统一行布局与图标操作，活跃区绿色柔和描边、其余灰色；父子会话用嵌套分组显示，操作只挂在父行、子会话完全跟随；活跃行只能轻归档（不动文件），移入回收站 / 删除在归档区与回收站里做。归档区可取消归档、移入回收站或彻底删除（父与子一起处理）；回收站可展开父子、单个 / 全部还原、彻底删除，并显示路径供复制。彻底删除普通会话需要输入完整标题确认，空白游离会话与「全部」操作也都有二次确认。各分区每页 30 条「加载更多」。
* 打开 **日程** 看聚合日历：上排等宽是 **今日** 和 **近期**——今日标题与日期分两行、和近期卡齐平；左右分栏（淡分割线）：左列今天的日程，右列三枚彩色可点计数（便签 / 未完成任务 / 活跃会话）；底部 **+ 便签 / + 任务 / + 笔记** 三个等宽白色主按钮（+ 笔记暂时禁用占位）。近期顶部有 1–14 天滑杆，拖动显示所选日期区间与该区间日程。下方月历 / 周历 / 日历铺满剩余高度（月历默认、周一起始、5–6 行自适应；周历一屏 8 小时可滚动）。点事件在鼠标附近弹卡片（来源 · 账号 · 日历），点其它区域或 Esc 关闭；外部事件只读，可复制或跳回原始客户端。面板打开时同步、之后每 15 分钟一次。
* 横向不出滚动条：面板变窄到阈值以下时，三个泳道收成只显示条数的窄列（泳道名 + 各分组条数）。泳道内卡片纵向超出时显示细滚动条并滚动，不再压缩卡片导致排版崩掉。
* 用 **@** 给任务卡关联 DSH 会话——一张卡可挂多个会话，一个会话也可服务多张卡。每个会话 chip 用边框和运行绿环区分状态，标题文字保持中性色（可用会话为绿色，已归档 / 不可用为中性灰）；正在跑任务的会话多一圈缓慢旋转的绿环（系统开启“减弱动态效果”时静止）。点 chip 在原位展开（最多占满卡片宽度，允许卡片增高；运行中边框动效跟随扩展后的 chip），显示上次运行、模型用时、轮数、步数、Token 用量；点其他位置立刻恢复，点箭头才跳转，也可从卡片移除。**@** 入口单独占一行、位于已关联 chip 下方；选择器是覆盖整页的浮层（不会被泳道裁切），列出与输入框 `@` 菜单同一份会话（含子代理会话）。关联不会覆盖卡片自己的标题或描述。

## 数据与隐私

* 便签、任务与日程镜像存在由官方存储服务管理的 DSH 存储域（`desk_one`）里，数据不出本机；日程只是外部日历的只读镜像，不会回写。
* 日程连接的密码 / 发布链接只保存在官方凭据库（`ctx.credentials`），记录里只留引用名；不会写进日志、HTML 或导出文件。
* 面板只调用插件自己的 host 路由 `/api/desk-one`（会话归档在 `/api/desk-one/sessions/*`，日程在 `/api/desk-one/schedule/*`），客户端不直接接触存储。
* Agent 工具（`desk_note_*`、`desk_task_*`、`desk_group_*`、`desk_schedule_*`）读写同一套对象；会话索引只存外键元数据、不复制对话内容，供任务/会话边解析，模型和界面永远看到同一份数据。会话关联只在本地数据里存不透明的会话 id，标题与运行状态从宿主界面实时读取，不外发。

## 已知限制

* 日程是**只读**聚合：不支持本地新建事件、写回外部日历或 iCalendar 订阅/发布；企业微信 / iCloud / Outlook 的真实连接需要你在首次使用时配置，协议行为以官方服务为准。
* 日程页的日程聚合受外部服务约束：企业微信重新获取同步密码会作废旧密码；iCloud App 专用密码在改 Apple 主密码后全部失效；Outlook 发布 ICS 由接收方刷新（通常 3–24 小时）。
* 会话归档与独立归档插件并存期间共用同一个回收站目录；归档插件退役后，回收站与归档管理统一在同桌里完成。
* 专注、搜索以及更丰富的任务字段（优先级、估算、标签）按仓库 spec 排期。
* 任务拖拽目前只支持指针操作，暂不支持键盘排序。
* 会话关联目前只做展示与跳转：会话开始 / 结束时不会自动推进卡片状态。
* Agent 工具创建的便签只有自动摆放的坐标，拖一次之后坐标才归你。
* 窗口变小时保存的坐标会临时夹在可见区内，空间恢复后回到原位置。
* 笔记的内容按独立规划推进，完成前保持空白。
