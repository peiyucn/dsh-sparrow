# dsh-desk-one

[English](README.md) | 简体中文

**办公桌**（Desk One）——DSH Web 里的个人办公桌：一个左侧栏入口、一块面板、一套统一对象模型，每个标签都建在同一套数据上。S0 先落地骨架与便签墙：点「＋」贴一张、随手拖着摆、拖角改大小、直接在贴纸上写字。

## 它是什么

* 左侧栏只有一个入口 **办公桌**；功能收在面板内的标签页里，不散落到界面各处。
* **总览** 长期定位是主标签，但内容还没设计，本版**保持空白**。
* **便签墙** 是第一个落地功能：一面自由摆放的便签墙，而不是一张录入表单。
* **任务板** 是第二个落地功能：固定三泳道看板（待办 / 进行中 / 完成），支持颜色标签、按天截止日期、拖拽推进与存档。

## 环境要求

* 要求 DSH 0.2.2-rc.1，与本仓库其它插件钉的版本线一致。
* Node.js 24 或更高，与 DSH 宿主要求一致。
* 不需要联网、不需要额外凭据、不需要账号配置。

## 安装

* `dsh plugin --profile web add @dsh-sparrow/dsh-desk-one`
* 安装后重启 dsh web；只刷新浏览器不够，客户端 bundle 由宿主启动时读入。
* 然后在鲸鱼侧栏里点 **办公桌**。

## 使用

* **总览** 目前是空白占位；打开办公桌默认落在便签墙，不让人先看到空页面。
* 点底部中央悬浮的 **＋**，或双击墙面空白处：贴纸会落在该位置、显示在最上层并自动获得输入焦点；两个悬浮按钮是磨砂玻璃材质，打光方向和主题化的输入框一致；空墙中央有很淡的两行提示。
* 墙面不滚动：贴纸始终被限制在可见区域内，缩小窗口也不会跑出屏幕。
* 直接在贴纸上写；失焦即保存，内容被清空的贴纸会直接移除，不在墙上留空贴纸。
* 按住贴纸正文拖动就能摆放；左上角有一枚紧凑的六点抓握纹，提示这里可以抓。点过或拖过哪张，哪张就显示在最上层，这个层级也会保存下来。
* 拖贴纸右下角可以改大小；位置与尺寸都会按便签各自保存。
* 鼠标悬停贴纸会显示颜色圆点与一组小图标操作；离开办公桌再回来，会停在上次所在的标签页。
* 贴纸上的**小垃圾桶图标**把它丢进垃圾桶但不删除（和 Smash 同一段飞散动画）；垃圾桶按钮用一条细分隔线与墙面操作隔开，点它是进入垃圾桶视图，行内图标可以恢复或永久删除。墙上最多 **100** 张便签、垃圾桶最多 **200** 张；垃圾桶顶部显示总数，一次渲染 10 行，点「加载更多」继续加载。垃圾桶按钮不挂角标——只有真正未读的东西才值得抢注意力。
* **Smash!** 是 **＋** 旁边的红色磨砂玻璃图标按钮：二次确认后把墙上所有便签一把扔进垃圾桶，带一段飞散动画；它常驻显示，墙上没有便签时点了没反应，点击其它地方或按 **Esc** 会取消确认；垃圾桶装不下时会被拦下并提示先清空。
* 打开 **任务板** 是固定三泳道看板：点列头 **＋**，或双击泳道空白处新建卡片；卡片显示自动换行的标题与描述、一个颜色圆点（点开五色板直接选）、一个按天截止日期标签。单击标题或描述进入编辑；平时文字是普通文本，所以**整张卡片都是拖拽区**。只剩一天截止的卡片会带琥珀色描边，逾期显示红字；只有 **完成** 列的卡片与分组能存档。
* 按住卡片任意位置就能拖：一张副本跟着鼠标走，泳道会高亮；掉在无效位置时卡片会飞回原处。拖进泳道改状态、拖到卡片上改顺序；拖动时目标泳道和分组会高亮，并用一条蓝色插入线标出松手后的准确位置。删除需要再点一次确认。
* 工具栏可切换 **手动排序 / 创建时间 / 截止日期**，**完成** 列可折叠。**＋ 分组** 在泳道里建一层真正的分组（可以一直为空）：卡片能拖进拖出、双击名字就地改名、拖六点手柄调整顺序。整组拖动和拖卡片完全一样：按住分组头拖动时整块（头 + 卡片）跟着鼠标走，拖到别的泳道直接连同卡片一起移动（移回来也一样便宜），同泳道内放下则调整分组顺序；删除分组只解散分组、卡片回到未分组。**完成** 列的分组头还会多一个存档按钮：整组连同卡片离开板面，存档视图里以一条分组条目展示；恢复会把整组和卡片一起拉回，删除存档分组则连同卡片一起彻底删除。**存档** 里可以恢复或永久删除存档任务。
* 横向不出滚动条：面板变窄到阈值以下时，三个泳道收成只显示条数的窄列（泳道名 + 各分组条数）；内部滚动条视觉上隐藏，但仍可滚动。

## 数据与隐私

* 便签存在由官方存储服务管理的 DSH 存储域（`desk_one`）里，数据不出本机。
* 面板只调用插件自己的 host 路由 `/api/desk-one`，客户端不直接接触存储。
* Agent 工具（`desk_note_*`、`desk_task_*`、`desk_group_*`）读写同一批便签、任务与分组，模型和界面永远看到同一份数据。

## 已知限制

* S1 已交付便签与任务板；专注、日历以及更丰富的任务字段（优先级、估算、标签）按仓库 spec 排期。
* 任务拖拽目前只支持指针操作，暂不支持键盘排序。
* 便签暂不同步到任何外部服务；Outlook 与企业微信日程同步会在后续步骤接入。
* Agent 工具创建的便签只有自动摆放的坐标，拖一次之后坐标才归你。
* 窗口变小时保存的坐标会临时夹在可见区内，空间恢复后回到原位置。
* 总览的内容与联动规则设计完成前，保持空白。
