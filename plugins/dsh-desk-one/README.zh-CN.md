# dsh-desk-one

[English](README.md) | 简体中文

DSH Web 里的个人「桌面」：一个左侧栏入口、一块面板、一套统一对象模型，每个标签都建在同一套数据上。S0 先落地骨架与便签墙；任务、看板与日历在后续版本里沿同一模型扩展。

## 它是什么

* 左侧栏只有一个入口 **桌面**；功能收在面板内的标签页里，不散落到界面各处。
* **今天** 是主标签，也是联动中心：便签、任务与日程后续都在这里聚合与关联。
* **便签** 是第一个落地功能：新建、编辑、置顶、改色、搜索与删除。

## 环境要求

* 要求 DSH 0.2.2-rc.1，与本仓库其它插件钉的版本线一致。
* Node.js 24 或更高，与 DSH 宿主要求一致。
* 不需要联网、不需要额外凭据、不需要账号配置。

## 安装

* `dsh plugin --profile web add @dsh-sparrow/dsh-desk-one`
* 安装后重启 dsh web；只刷新浏览器不够，客户端 bundle 由宿主启动时读入。
* 然后在鲸鱼侧栏里点 **桌面**。

## 使用

* 用面板顶部的标签栏在 **今天** 与 **便签** 之间切换。
* 在 **便签** 里输入标题或正文后点 **保存**；标题留空时取正文首行。
* 鼠标悬停便签卡片会显示 **置顶**、**编辑** 与 **删除**；**删除** 需要在同一张卡片上再点一次确认。
* 搜索框按关键词过滤便签，标题与正文都参与匹配，大小写不敏感。

## 数据与隐私

* 便签存在由官方存储服务管理的 DSH 存储域（`desk_one`）里，数据不出本机。
* 面板只调用插件自己的 host 路由 `/api/desk-one`，客户端不直接接触存储。
* Agent 工具（`desk_note_*`）读写同一批便签，模型与面板永远看到同一份数据。

## 已知限制

* S0 只实现便签；任务、看板、专注与日历按仓库 spec 的步骤排期。
* 便签暂不同步到任何外部服务；Outlook 与企业微信日程同步会在后续步骤接入。
* 本插件暂无设置页，也没有导入 / 导出界面。

## 开发

* 单插件检查：在本目录跑 `npm run verify`（类型检查、构建、测试、打包检查）。
* 仓库级检查：在仓库根跑 `pnpm run verify`。
