English | [简体中文](CHANGELOG.zh-CN.md)

All notable changes to `dsh-desk-one` are documented here. The format follows Keep a Changelog and the version numbers mirror the official DSH release line.

## [0.2.2-rc.1] - 2026-11-06

* First release: one **Desk** entry in the left sidebar hosting a tabbed panel, with the **Today** tab reserved as the future aggregation hub.
* Sticky notes wall: add a note with the floating **＋**, write directly on the sticky, drag it anywhere on the wall, switch colors and delete on hover; text and positions persist through the official DSH storage domain, and agent tools expose the same notes to the model.
