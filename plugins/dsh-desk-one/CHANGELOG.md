# Changelog

English | [简体中文](CHANGELOG.zh-CN.md)

All notable changes to `dsh-desk-one` are documented here. The format follows Keep a Changelog and the version numbers mirror the official DSH release line.

## [0.2.2-rc.1] - 2026-11-06

* First release: one **Desk One** entry in the left sidebar hosting a tabbed panel; **Overview** is the main tab that gathers what is on the desk.
* Notes wall: add a note with the floating **＋**, write directly on the sticky, drag it anywhere inside the visible wall (no scrollbars), click or drag a sticky to bring it to the front, resize it from the bottom-right corner, switch colors and delete on hover; the sticky is square paper, and text, position, size and layer order persist through the official DSH storage domain.
* Agent tools (`desk_note_*`) read and write the same notes, and the panel remembers the tab you were on when you come back.
