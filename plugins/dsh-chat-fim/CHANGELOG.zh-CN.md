# 更新日志

简体中文 | [English](CHANGELOG.md)

## 0.2.0-rc.2（2026-10-08）

- 适配官方 dsh 0.2.0-rc.2（Web 与桌面端）。

## 0.1.5-rc.2.1（2026-09-21）

- 修复刚启动 DSH 时联想开关不跟随所选模型的问题。

## 0.1.5-rc.2（2026-09-10）

- 版本线对齐官方 dsh 0.1.5-rc.2。
- 在 dsh 0.1.5 上，联想开关与候选菜单恢复显示。
- 很长的会话里联想也保持流畅。
- 联想跟随当前主模型，默认回退到 deepseek-flash。

## 0.1.2-rc.1.1（2026-09-09）

- 联想只在所属会话上显示。
- 遇到本插件尚不支持的 dsh 版本时，插件自动停用，dsh 仍可正常使用。
- 弹窗打开时，联想卡片随背景一起模糊。
- 本插件不认识的会话不再请求联想。

## 0.1.2-rc.1（2026-09-05）

- 版本线对齐官方 dsh 0.1.2-rc.1（稳定线）。
- 切换模型后，FIM 开关立即跟随所选模型。
- 点击联想卡不再抢走输入框焦点，Tab 仍可用。
- 其它网站不能再代替你发起联想请求。
- 草稿里用 @ 引用了文件或提示词时，Tab 采纳也能正常工作。
- 联想卡左下角新增 🐦 dsh-sparrow 品牌行。

## 0.1.0 (2026-09-02)

- 首个稳定版。

## 0.1.0-alpha.3 (2026-09-02 · pre-release)

- 修复显示联想时输入卡片周围的间隙。

## 0.1.0-alpha.2 (2026-09-01 · pre-release)

- 版本线对齐 0.1.0-alpha.2；功能无变化。

## 0.1.0-alpha.1 (2026-09-01 · pre-release)

- 首个版本。
- 停顿后提示你可能要输入的内容。**Tab** 采纳、**Esc** 关闭。
- 联想跟随主模型，卡片显示所用的模型与温度。
- 开关文案中英统一为 **FIM**。
- **触发灵敏度三档**（高 / 中 / 低）决定什么时候触发联想；选择会被记住。
- 续写语言跟随草稿，建议在第一个句末标点处收尾。
- 只是复述对话的建议会被丢弃。
- 开关默认关闭、状态会被记住；主模型不是 DeepSeek 时保持隐藏。
- 使用 dsh 里已配置的 DeepSeek API key，不把它发到浏览器；新会话页同样可用。
