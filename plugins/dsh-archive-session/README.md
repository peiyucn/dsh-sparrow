# dsh-archive-session（规划中）

DeepSeek Harness（DSH）Web 插件 —— 归档会话管理（dsh-sparrow 合集成员）。

与官方「轻归档」互补：官方把会话从侧边栏藏起来；本插件在**工作区工具栏**加一个入口按钮，点开弹窗列出所有轻归档会话，每行提供**三档操作**——

* **轻量标题（`@` 仍可拉回）**：会话保留在 `@` 池，但标题走轻量 / 缓存读取（快，路线 A）——默认档。
* **备份（`@` 不可达，可逆）**：把会话目录移到插件备份夹，`@` / 列表不再出现；可移回恢复。
* **删除（`@` 不可达，不可逆）**：彻底删除会话日志，不可恢复；不可逆警示 + 强确认。

主 UI 保持干净，只多一个按钮。
